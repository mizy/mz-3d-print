# 重建当前四偏心轮版

请从 GitHub 仓库副本重建。公开 Pages 只放当前交付，不镜像 History 基线和旧包。

FreeCAD Python 环境须可加载 `FreeCAD`、`Part`、`TechDraw` 和 `MeshPart`。下列命令在 `latest` 执行，`python` 指 FreeCAD 应用内的 Python，先设置其库路径。在 macOS，例如 `F=/Applications/FreeCAD.app/Contents/Resources; export PYTHONPATH="$F/lib:$PWD/Source"`，用 `"$F/bin/python"` 替代下列命令中的 `python`。

1. `python Source/build_four_cam_geometry.py ../History/Inputs/Rear_Keys_2026-11-26_Closed.step STEP`
2. `python Source/export_four_cam_parts.py .`
3. `python Source/build_horizontal_expansion.py STEP STEP; mv STEP/expansion-fit.json QA/`
4. 从 `../History/Archived/Rear_Slide_Key_2026-11-26.tar.gz` 解出旧的 `Right_Bay_Frame_P1S_PETG_UNSLICED.3mf` 给打印包脚本，只读取全局设置与容器模板，不继承旧几何/对象引用：`python Source/build_right_bay_3mf.py . Print/Right_Bay_Frame_P1S_PETG_UNSLICED.3mf /path/to/old.3mf`。
5. `python Source/verify_stop_travel.py . QA/travel-stop-readback.json`，回读 STEP 验证限位接触和解除后取出。
6. `python Source/build_four_cam_review.py .`。模型/截图数据取这一批回读的 STEP，非手绘轮廓。用支持 WebGPU 的 Chrome 查看，加上 `Source/verify_four_cam_review.cjs` 自动化验收。打印包只做几何、元数据及引用验证，不切片。用独立 Python 环境的 lib3mf 2.5.0 运行 `python Source/verify_3mf_archive.py Print/Right_Bay_Frame_P1S_PETG_UNSLICED.3mf`，通过条件为 21 件、0 警告。

尺寸基准和装配检测见 `QA/`。时间戳、STEP 写入环境或网格库版本变化会造成字节不同；发布前重新生成校验和，并用实际 STEP 核对投影。
