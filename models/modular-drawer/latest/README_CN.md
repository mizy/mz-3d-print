# 模块化抽屉 · 紧配后板上口

统一从 [当前 HTML 评审](index.html#joints) 查看关合总成、后板、双 T 滑键、止退片和四实体试配样件。三视图与 3D 都使用同批 STEP；旧机构不在当前评审中展示。

- **保留现有件。** 78 mm 侧高拉篮、原侧板、前梁、下方锁件及导轨不改。仅后板上部两个接口改为双 T 滑键，每口另用一枚从顶部放入的止退片。原侧板的旧槽不是这次调整对象。
- **清理旧台阶。** 后板内侧旧的 0.30 mm 矩形落差已统一削到 Y238.80。双 T 插键导入端简化为四个平面倒角；只保留挑出与止退确实用到的槽。止退销保留平直销身和顶部取出槽。
- **紧配与防松是两件事。** 新后板的双 T 工作面按名义零间隙，入口保留倒角；止退片挡住沿深度抽出的方向，活动槽保留自己的装拆间隙。背部最外 Y245、顶边 Z100，均与框架外轮廓齐平。拉篮后部名义净空 0.80 mm。
- **装拆。** 从后面插双 T，再从顶部放止退片；拆卸顺序相反。叠装挡住顶部时须先预装或留工具空间。先试插键在已打印侧板中的匹配，再试一角样件，不建议零间隙实物未经干装便直接打整后板。
- **已有证据。** 回读 19 件总成与四实体小样；抽拉 23 个位置、插拔 18 个位置、止退片落入 10 个位置、以及后向挡肩均有名义 CAD 记录。没有实测插拔力、抗振、磨损、承重或切片。

评审查看器使用 GitHub Packages 已发布的 `@mizy/mz-3d-viewer@1.0.0`，全部内嵌。3D 需要支持 WebGPU 的浏览器和图形加速；无 WebGPU 仍可打开三视图和下载 STEP。历次旧总成、模型、排盘和旧评审从项目的 `History` 查找，不出现在当前报告。

3D 默认显示边线；鼠标移到部件上实时高亮，单击锁定选中，Esc 清除。右键可隐藏、单独显示或恢复部件；双击选中部件适应视图。
