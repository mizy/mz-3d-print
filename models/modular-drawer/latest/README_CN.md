# 模块化抽屉 latest：背面齐平、后板四颗偏心轮

- **上、下锁座。** 上轮 Ø8.20 mm，背面开口 Ø8.56 mm，轮座深 11.65 mm，端面内退 0.25 mm。先装轮，轮处在解锁角时从相应侧边送入直拉杆，再转轮。两枚后上轮从背面操作，后下及前梁从原内侧操作。上轮与原侧板槽配合；不需要原止退片。
- **外形与让位。** 外背与侧板后缘同在 Y245，深 240 mm。原广面厚 6.20 mm，两个锁座局部向内至 12.65 mm；拉篮两后上角各约 20 mm 宽，最多损失 6.45 mm 的局部深度，保持封闭。底板、滑轨及前挡位置不动。不把旧平背拉篮当即插即用。
