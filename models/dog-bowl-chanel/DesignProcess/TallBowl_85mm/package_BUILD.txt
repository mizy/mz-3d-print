CAD source requirements: Python 3.12, cadquery 2.7, svgpathtools.
Run each model's build.py in its own directory. LV uses its included SVG logo source.
LV: run remesh.py and print_helpers.py after build.py for fine mesh and print samples.
Validation: Python + trimesh; run validate.py. Blender renders generated by render.py.
Build scripts contain editable dimensions; STEP is editable CAD geometry, not a native feature-history CAD document.
Do not mix assembly-position parts with the flat-print duplicate logos as one object.
