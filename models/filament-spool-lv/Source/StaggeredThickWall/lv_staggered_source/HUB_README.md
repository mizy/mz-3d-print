# 官方筒体参数化逆向模块

来源为官方 Wiki 直接链接的 wide/narrow STL，与用户 Downloads 新下载文件逐字节一致。此处是官方附件几何的逆向基准，不是厂商原始特征树，也不是厂商尺寸/公差认证。

- 页面：https://wiki.bambulab.com/zh/knowledge-sharing/bambu-reusable-spool
- 宽附件：https://wiki.bambulab.com/knowledge-sharing/print-volume-limitations/bambulab_spool_wide.stl
- 窄附件：https://wiki.bambulab.com/knowledge-sharing/print-volume-limitations/bambulab_spool_narrow.stl

## 坐标与范围

原附件轴向为 X。右手刚体重定向：wide=(Y,-Z,33.70000076293945-X)，narrow=(Y,Z,X+33.70000076293945)。两片均外盘面为 z0，锁口朝 +Z。不要用只翻转轴向但不翻转另一轴的反射变换，否则锁口手性会错。

`official_hub.build_hub(part,p)` 生成 z2.7 以上的内外筒、完整四桥、卡口、宽筒两浅三角标记。底部支承环和入口倒角由 official_flange 提供；宽半纸芯定位键由 official_key 提供，不能只拿 hub 当完整线盘。

## 真实结构参数

- 两半轴孔基准 R27.5；入口倒角 .8（由法兰生成）。
- 宽内管 R27.5 至 z3.7，45°坡和 R1.5 过渡至 R31.4，外 R33.3，顶 z37.25，外顶倒角 .5。
- 窄内管内 R27.5、外 R29.7，顶 z34.1，内顶 .8 倒角。
- 宽外筒内 R39/外 R40.85，顶40.7；窄外筒内 R37.7/外 R40.65，肩25.7、颈27.9。
- 四桥宽1.2，宽半 z2.7..25.7，窄半 z2.7..20.7，完整贯通上下而非旧模型仅顶端短桥。
- 主齿及止退凸点由 narrow_lock 的旋转、圆弧草图、拉伸、锥面裁切生成。
- 宽锁口由两组可编辑圆弧/直线草图、锥面、斜平面、R3入口过渡圆角组成。草图与平面控制保存在 JSON；不是网格翻面，也没有运行时加载原 STL/BRep。
- 两个浅三角标记用少站位原生曲面拟合上限面与圆柱/锥体裁切；明确是容差逆向，不称完全解析零误差。

`DEFAULTS` / hub_parameters.json 的字段被真实读取。宽锁口径向随共享 wide_bore_radius 比例变化，轴向随 wide_inner_tube_top 平移；尺寸先进入草图/圆锥/平面构建，避免成品非均匀变换产生近重合BSpline曲面；独立修改该尺寸会改变卡口间隙，不能假定配合仍保持。窄孔/外壁、桥宽、锁齿/凸点参数分别有真实几何作用。全局径向/轴向缩放在模块内可用，但总项目入口为避免孤立缩放未联动而暂拒绝非1值。参数输入域不是已验证的所有组合，需重新检查装配/壁厚/实体和切片。

## 名义圆修复，非网格补洞

早期宽草图从 STL 截面拟合出略偏心的“R31.4基圆”，与精确筒孔融合后出现极薄 sliver 面：一柱 R31.397249858，轴偏(.001249269,.002467183)，另一柱 R31.400220587，轴偏(-.000182069,-.000167475)。近重合边原生距离约2.17e-5mm，却因不同离散站位形成三角网格缝。

最终将属于名义 R31.4 基圆的草图控制点归一为精确同轴圆，再重新原生生成。控制点最大移动 .002724mm；不是焊接/补洞网格。宽 hub 143→126面，体积改变 -.68831mm³。默认源已经采用此修正。

独立 STEP 网格复核：.01/.1 为9328三角、.002/.05 为26282三角，均0开放边/0非流形、绕序一致；z34.5/35切片恢复闭环。完整宽盘由主构建方独立回读170面，完整窄盘107面。

## 测量验证与限制

- 窄锁口实际STEP：16个独立高度最大边界采样Hausdorff .01113mm。
- 宽入口R3：6个重点高度最大约.00468mm；其余锁口抽检约.005mm。
- 宽浅三角标记：7高度最大 .02860mm，在z17.75浅坡处。
- 宽内管R1.5过渡：z8.1对STL弦化边界约.00949mm。
- 主构建方完整件：宽36截面最大.028921mm，体积比官方STL+.0143%；窄22截面最大.01149mm，体积+.015%。

均为列明截面/采样的证据，不是连续全表面误差上界、打印公差、强度或装配认证。参数改动后的有效实体也不自动等于保持全部配合。失败试验文件只作研究，不能与最终默认模块混用。

变参额外回归：wide_bore_radius=31.6 后锁口z36最小半径30.09045，125面有效且网格0开放/0非流形；外筒半径41.1+桥宽1.5也有效闭合。修复前成品非均匀缩放路线曾有8开放边，已弃用。最终默认尺寸改为构建前传递后体积差<1e-8mm³，126面及闭合结果不变。
