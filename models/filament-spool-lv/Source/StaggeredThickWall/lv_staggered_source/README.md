# LV OPEN ARCH · 大面积错位长窗

2026-11-19。改为8个均匀长窗/层，内外相差22.5°。不是上一版矮三角的简单放大：窗身拉长、上部50°尖拱收口、底角1.5mm斜切；取消遮挡孔洞的宽斜膜。蓝外筒/橙内筒仅为预览配色，每半仍为一个实体。

## 本次参数
- 各窗最大角向包络20°，间隔45°；两层错位22.5°，角向留缝不径向对穿。
- 外窗底z5.5；宽半顶z36、窄半顶z23.2。内窗z6–28。窗宽由相应最小壳半径和10°半角参数确定，约外12.8、内9.5–10.9mm。
- 按展开前的平面切割轮廓面积，外窗宽半为上版2.85倍、窄半1.78倍；内窗约5.5–6.1倍。这不是曲面通风面积、切片省料比例或强度结论。
- 保留名义低段4mm筒壁、19.5–22.5渐退、上下连接环、盘面和LV花纹。原径向桥的内部材料保留，但大窗改变了它们与外壁在开窗高度内的连接方式，不能称承载路径完全不变。
- 保留实际配合区而不是整段z≥26一刀切保留：内管z≥29；外宽筒z≥37.5；外窄筒z≥24.3。本次在这些区域与原基准的布尔对称差为0。

## 参数化与再生
安装 requirements.txt，然后：
`python build_light.py --config light_parameters.json`

自动识别本包Source/Models布局和Mac原共享项目布局，输出：
- LV_OPEN_ARCH_A_wide.step
- LV_OPEN_ARCH_A_narrow.step

可用 `--output` 指定目录，或用环境变量 `LV_MODELS_DIR` 指定检查/预览目录。两份STEP各为一个有效原生BRep，原点分别居中。完整可编辑特征定义是JSON/Python；STEP不自带完整历史树。共享基础文件在Mac保留原相对链接，本下载工程包将其展开以便独立运行。

## CAD验证与装配假设
- 每半有效单实体；分件STEP回读；无网格转STEP实体。
- 每半16处窗口/对侧壁体积探针，开窗为空、对侧壁完整。
- 两外盘面相距67.4mm。窄半绕X180°再绕Z旋转，平移至z67.4；44°和50°名义装配无几何干涉，50°轴向偏移2/5/10mm抽检也无干涉。0°仍有原基准干涉，不能当作正确装配姿态。
- 前版的转角抽检显示44–48°拔出时卡扣接触，50–52°可直进退；这仅支持插入后旋转锁合的解释，不是厂商角度或实际锁紧力认证。
- 轴孔名义最小55mm；整件Ø54.9mm圆柱体通孔检查。
- 筒外径81.7/81.3mm，定位键局部到R43.7、z2.5–7.8，纸芯须有匹配缺口。两侧3.6mm筋之间轴向包络60.2mm，盘外径200mm。实际纸芯内径、缺口、宽度未测，不能保证任意耗材适配。

## 未验证内容
没有切片、有限元、实际装配、满卷、疲劳或AMS动态测试。不因加厚、实体有效或面积增加就宣称强度合格。尖拱斜顶用于减少大面积水平封口，但尖端及局部桥接是否需支撑由用户自行切片。打印收缩、线宽和层向性能均未验证。A槽只停放线头，送退丝前释放。
