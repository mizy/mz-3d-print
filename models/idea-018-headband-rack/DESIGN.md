## 1. 安装方案对比（先解决「装得住」，再谈好不好看）

主人给的三条路是：**放到**桌面 / **戴到**玩偶头上 / **架在**玩偶上方。逐个方案算「靠什么力固定、接触面在哪、会不会翻」，再挑。

| # | 方案 | 靠什么力固定 | 接触面 | 会不会翻 / 料量 | 结论 |
|---|---|---|---|---|---|
| A | **桌面底座环龙门架**（底座环 + 6 立柱 + 顶面 3 根晾杆 + 2 根侧梁，一件打印） | 重力 + 底座环与桌面的摩擦（μ≈0.4；按实打质量 118g 自重 + 3 条湿发带算，水平 96g 才开始滑动，见 §5） | 底座环 4 根杆的底面，**4192 mm²**（外廓 150×128，接触带宽 8mm，占全部底面的 22%） | 支承多边形 150×128；3 条湿发带全挂在多边形内（杆位前后 ±60 ⊂ ±64），**负载反而加稳定（+29%）**；顶部要 ≥54g 水平推力才翻 | **选它** |
| B | 桌沿 / 层板 C 型夹（夹住桌面边缘，立柱上挑，横杆悬出） | 夹持螺纹预紧 + 夹口摩擦 | 桌沿上下面各一条窄带 | 桌沿厚度未知（15/25/40mm 差一档就夹不住或夹不上）；悬臂长 60–100mm，湿发带重力给夹口的**倾覆力矩**（M≈0.12N×0.06m=7.2mN·m）全压在夹口摩擦上；夹身要另出件、还要夹紧机构 | 否：**多一个未知量（桌沿厚度）换来的只是一个位置**，且受力最不利 |
| C | 3M 胶贴墙 / 显示器背面（贴片 + 挂臂） | 胶层剪切 | 平面（墙面 / 显示器背板） | 墙面不是主人的桌面场景；湿发带 120g 长期挂 + 潮湿环境 = 压敏胶蠕变剥离（3M 官方数据：VHB 长期剪切载荷建议 ≤ 每 cm² 几十 g，且要求洁净、施压、室温）；显示器背面属于别人的壳，贴了没法还原 | 否：使用场景不对，且**主人没说要上墙** |
| D | 磁吸（底座埋磁铁，吸铁质桌面 / 显示器支架） | 磁吸力 | 磁铁面 | 桌面是木头（照片里是木纹桌），吸不住；埋磁铁的孔要按磁铁实测尺寸留（又是一个未知量）；钕磁铁吸力随间隙平方衰减，打印件的平面度吃不住 | 否：**桌面材质不支持**，等于把「装不上」换了个形式 |
| E | 戴在玩偶头顶的可拆小帽架（发箍式卡在头上） | 夹持 + 摩擦 | 头部两侧曲面 | 玩偶头部**没有实测尺寸**（半径、耳距、发量），树脂件表面滑；湿发带挂载点高（头顶 z≈175），力臂最长，**玩偶本身可能被带倒**（不是架子翻，是把玩偶带翻） | 否：最讨喜但最装不住——两个未知量 + 最不利力臂，正是上一版被否的坑 |
| F | 架空在茶叶盒顶上的双立柱桥（把盒顶当支撑面） | 立柱脚压在盒顶 + 摩擦 | 盒顶面（两个小圆脚） | 盒顶是**斜面/有浮雕花纹**的盖子（照片里「桂花」盒盖有图案），平面度未知；立柱把它变成「高重心 + 小接触面」的塔；且占用盒顶（主人自己也要放东西） | 否：接触面不确定 + 重心被抬高 |

**取舍一句话**：A 的安装方式**只依赖桌面（永远存在、永远水平、面积足够）**，唯一依赖玩偶的地方是「净宽 / 净高」两个可调参数（量到就改，量不到也能先打）；B/C/D/E/F 全都把「装得住」押在一个主人没量过、甚至可能不存在的界面上。所以主方案选 A。

**「戴在头上」这条**：不作主方案，理由是几何上不成立（见 E 行）——已写进台账关掉。

## 2. 选定方案的结构

```
        ┌── 顶面格栅（5 根：3 根晾杆 + 2 根侧梁，上宽 8 / 下缘 1.6 的楔形截面）
        │
   ╷    ╷      ╷          ← 6 根立柱（8×8）：y = -60 / 0 / +60，左右各一列
   │    │      │
  ─┴────┴──────┴─         ← 底座环（4 根 8×8 杆围成 150×128，贴桌面）
```

- **晾杆 3 根**，沿 X 架在左右两列立柱顶上，Y 位置 −60 / 0 / +60（间距 60mm，发带各自垂在 3 个互相平行的竖直面里，不压叠）。
- **侧梁 2 根**（x = ±71）沿 Y 把三根立柱的顶连起来 → 每侧立柱 + 底环 + 侧梁构成**闭合四边形**（平面内刚性），顶面 5 根互相咬合 → 整件是**一件刚性空间框架**，不用任何斜撑。
- **立柱顶面 = 晾杆顶面 = 侧梁顶面**（都平齐），顶面是干净的格栅。
- **截面形状是免支撑的关键**：所有顶面构件做成「上宽 8 / 下缘 1.6」的楔形，两侧面与竖直方向夹角 24.6°（< 45° 自支撑），朝下的**平面只剩 1.6mm 宽的细棱**（见 §5 桥接说明）。

**靠什么力固定 / 接触面在哪**

- 固定靠**重力**：整件自重压在桌面，接触面 = 底环 4 根杆的底面 ≈ **43 cm²**（见 `model.py` 的 `foot_area`），落在木桌上是面接触，不硌桌面、不需要胶 / 夹 / 螺丝。
- 工作负载（3 条湿发带，按每条 ≤40g 估、共 ≈120g）**全部落在支承多边形内**：前杆在 y=−60、后杆在 y=+60，底环外沿到 ±64 —— 负载的水平力臂只有 4mm，对稳定性的贡献是**正**的（+2%），不会把架子带倒。
- **翻倒判据**（`model.py` 里算，数值见 §5）：绕前/后底沿翻需要顶部水平推力 F = (W_自重×64 + 负载的附加力矩) / post_top；绕左右底沿翻 F = W×75 / post_top。

**为什么不做斜撑**：每侧的「3 根立柱 + 底环纵杆 + 顶面侧梁」本身就是一个**闭合四边形**（平面内刚性），
顶面 3 根晾杆 + 2 根侧梁在 6 个节点互相咬合成**顶格栅**，把两片侧架在 X 方向锁死 —— 整件是
「底环 + 顶格栅 + 6 根竖杆」的箱式框架，斜撑一根都不用，省料又好看。

## 3. 参数表（`model.scad`，改一行重出）

| 参数 | 默认 | 含义 / 改了会怎样 |
|---|---|---|
| `clear_x` | 134 | 左右侧架**内壁净宽**（= 晾杆净跨）。玩偶最宽处必须小于它 → 主人要量的第 2 个数 |
| `post_top` | 195 | 立柱顶面高 = **整件总高**。晾杆下缘在 `post_top−7`，要压在玩偶头顶之上 → 主人要量的第 1 个数 |
| `frame_t` | 8 | 侧架 / 立柱在 X 方向的厚度 |
| `post_w` | 8 | 立柱截面宽（Y），与 `frame_t` 同为 8 → 立柱 8×8 |
| `base_h` | 8 | 底座环高（贴桌面那一圈） |
| `base_w` | 8 | 底座环杆宽（水平方向）→ 外廓 Y = `2×bar_y_spacing + base_w` |
| `bar_y_spacing` | 60 | 三根晾杆的 Y 间距（杆位 −60/0/+60）。湿发带厚度一般 <15mm，60mm 足够分开 |
| `bar_top_w` | 8 | 晾杆**上平面宽**（发带落在这里）：够宽 → 不压出折痕；上宽下窄 → 挂在杆上的圈**滑不下来**（这就是台账里问的「防滑凹槽」的答案：不做凹槽，靠上下宽度差） |
| `bar_bot_w` | 1.6 | 晾杆下缘宽。**唯一的桥接量**：1.6mm 细棱跨 134mm，比 8mm 宽平面好打得多；调到 3 会更稳但底面更宽 |
| `bar_h` | 7 | 晾杆截面高（决定抗弯截面模量 W，见 §5） |
| `hook_*`（8 个） | — | 可选配件的尺寸（挂杆小钩），见 §6 |
| `wet_band_g` / `wet_bands` | 40 / 3 | **设计假设**（不是几何）：单条湿发带重量、同时晾几条。只进受力校核，主人量到就改（见 §4 第 3 个数） |
| `rho_pla` / `rho_petg` | 1.24 / 1.27 | 材料密度（取自 `runtime/filament-prices.json`，2026-10-24 快照），只用于算自重与成本 |

外廓（脚本自检要求 = 参数）：
`X = clear_x + 2×frame_t = 150`，`Y = 2×bar_y_spacing + base_w = 128`，`Z = post_top = 195`。

## 4. 要主人实测的尺寸（最多 3 个，量到就改一行）

| # | 量什么 | 怎么量 | 量到后改哪 |
|---|---|---|---|
| 1 | **玩偶 + 它坐的茶叶盒的总高**（桌面 → 头发最高处） | 直尺垂直靠桌面，从桌面量到顶端最高点（包括支棱起来的头发/耳朵）；照片里它坐在茶盒上，所以要**量到桌面**，不是量玩偶本身 | `post_top` = 这个数 **+ 12**（留 12mm 余量） |

| 3 | **一条发带湿透后的重量** | 发带泡湿拧一下（就是平时晾的状态），上厨房秤 | 只用于核对 §5 的受力余量；按默认「≤40g/条」设计的话不用改 |

> 3 个数都不给也能打：默认值按「玩偶+底座总高 ≤183、最宽处 ≤124」设计，能当**普通桌面发带架**先用；只有「架在手办正上方」这件事需要数 1、2。
> 照片只能当比例参照（≠ 实测）：按画面比例**粗估**「手办+茶盒」总高 ≈175mm 量级（俯视透视 + 头发支棱，实际误差可能 ±30mm），
> 默认净高 188 只是**为了覆盖这个量级**、不是拿照片当尺寸；照片的作用只有一个：确认它是「Q 版坐姿 + 茶盒底座」这种高瘦形，所以选"架在上方"而不是"戴在头上"。

## 5. 受力判断（湿发带下垂 → 横杆跨距与杆径）

**杆件截面**（楔形：上宽 8 / 下缘 1.6 / 高 7，侧面与竖直 24.6°）由 `model.py` 精确算面积、形心与惯性矩：

| 量 | 值 | 算法 |
|---|---|---|
| 面积 A | 33.6 mm² | 梯形 (8+1.6)/2×7 |
| 形心离**下缘** | 4.278 mm | h(a+2b)/(3(a+b))，a=下缘、b=上宽 |
| 惯性矩 I | 116.87 mm⁴ | h³(a²+4ab+b²)/(36(a+b)) |
| 抗弯截面模量 W | **27.32 mm³** | I / c_max（c_max = 4.278，最远纤维在**下缘**） |
| 侧面与竖直夹角 | 24.57° | < 45° → 免支撑（这是断面形状的全部意义） |

**最不利工况**：净跨 L = `clear_x` = 134mm（左右立柱内壁之间），载荷 P 落在跨中 →
M = P·L/4，σ = M/W，挠度 δ = P·L³/(48·E·I)（PLA E=3.5GPa σ_b=50MPa，PETG E=2.0GPa σ_b=47MPa，都取保守下限）。

| 工况 | P | M | σ | 安全系数 | 跨中挠度 |
|---|---|---|---|---|---|
| 单条湿发带 40g | 0.392 N | 13.1 N·mm | **0.48 MPa** | PLA **104×** / PETG **98×** | 0.048 / 0.084 mm |
| 3 条同挂一根杆 120g | 1.177 N | 39.4 N·mm | 1.44 MPa | 35× / 33× | 0.144 / 0.252 mm |
| 误挂湿毛巾 300g | 2.94 N | 98.6 N·mm | 3.61 MPa | 14× / 13× | 0.36 / 0.63 mm |

**结论（这就是"横杆跨距与杆径的粗略受力判断"）**：

1. **强度完全不是约束**：设计工况的弯曲应力 0.48 MPa，比 PLA/PETG 的强度低两个数量级（余量 ~100×）。
   就算有人挂条 300g 的湿毛巾，也还有 13× 余量。**所以没必要为了"怕压弯"把杆加粗** —— 加粗只会更笨重、更挡视线。
2. **真正决定截面的是另外三条**：① 免支撑 ← 上宽下窄的楔形（24.6° 自支撑）＋下缘细棱（1.6mm 宽，桥好打）；
   ② 不压折痕 ← 上平面 8mm 宽（不是细圆杆，湿发带挂久了不会勒出一道印）；
   ③ 不滑落 ← 上宽下窄本身 = 天然防滑，圈挂在上面越坠越往中收，不用做凹槽（台账里那个问题就此关掉）。
3. **层间是唯一的力学弱点**：杆是水平放的，弯曲拉应力落在杆的**上下表面**，与打印层方向垂直（最有利）；
   真正的长期风险是**蠕变**（室温下低应力也会慢慢变形）与**层间剥离**，所以潮湿 + 长期挂 → **推荐 PETG**
   （韧性、抗疲劳、耐潮；PLA 够挺但脆，且 >60℃ 会软，别放暖气边）。同一套尺寸换 PETG 只需改 `rho_petg` 算重量。

**它靠什么站住（安装自洽性，数字来自 `check.py` 的 D 段）**

| 判据 | 数字 | 说明 |
|---|---|---|
| 贴床面积 | 4192 mm²（占地面的 22%） | 底环 4 根杆整条底面受力，木桌上是面接触，不需要胶/夹/螺丝 |
| 重心 | z = 89.0 mm（总高 195） | 重心低（立柱质量均匀分布），y=0 对称 |
| 负载在多边形内 | 杆位 ±60 + 半宽 4 ≤ ±64 | 前后杆整体落在 150×128 支承多边形**内**；负载平均力臂是**向内 24mm** → 反而把稳定性抬高 **+29%** |
| 翻倒阈值（前后） | 顶部水平推力 **54g** | F = (W×64 + 负载力矩)/195；W 按 cost.mjs 算出的实打质量 121g(PETG) |
| 翻倒阈值（左右） | 顶部水平推力 **46g** | F = W×75/195 |
| 滑动阈值 | ≈96g | μ×N = 0.4×(1.18N + 1.18N 负载) |
| 结论 | **负载带不倒，蹭一下不倒，手推会倒** | 3 条湿发带的重量（1.18N）对稳定性是**正贡献**；要翻得靠顶部 46–54g 的外力（猫扒/手肘），属"桌面小架子"的正常量级。想更稳：底环中央（桌面上、圈内）放 200g 配重硬币，阈值升到 ~120g；或把 `depth` 加大 |

## 6. 打印与装配

- **打印姿态**：模型坐标系就是打印姿态（Z 向上，底座环贴床）。全部竖直壁 + 顶面构件的 24.6° 楔面 → **免支撑**。
- **唯一的桥**：3 根晾杆 + 2 根侧梁的下缘细棱（宽 1.6mm），跨 134 / 112mm。细棱桥下垂量级 ≤0.5mm，出现在**杆的底面**（朝下、正常视角看不见）。介意的话：把 `bar_bot_w` 调到 3（桥更宽更稳），或切片时只给这 5 条细棱手工加一条针状支撑。
- **材料**：PETG 首选（潮湿 + 长期受力，韧性好、不易断）；PLA 也能用（够挺，但别放窗边/暖气旁，>60℃ 会软）。
- **可选配件 `headband-hook`（挂杆小钩）**：坐在晾杆顶上，两片限位翼卡住 8mm 上平面定心（内净宽 8.8 = 杆顶 8 + 单边 0.4 打印公差），一侧垂一根 22mm 的小尖钩，钩根**正落在限位翼正下方**（受力直接沿板压回钩体，不是悬臂）。
  用途：同一根杆上再挂 1–2 条细发带 / 发圈（主人要的"2–3 条"主件已经够，这是加量）。**整只靠重力坐在杆上，能随手拿起来换位置**（不掉、也不锁死）。尺寸 24×12.8×25mm、1.744 cm³，**一次排 4 个**打一盘。
- **建议切片参数**：层高 0.2 / 墙 3 圈 / 填充 15%（尺寸精度靠外形，不靠填充）；主件不需要任何支撑。
- 装配：**主件一件打印出来就能用**，不用拼、不用胶、不用螺丝；配件是「坐上去」的，不用装。
