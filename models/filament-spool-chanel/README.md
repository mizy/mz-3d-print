双 C 料盘 · 外滚环、主筋与筒壁加厚版

用途：几何审查、自行切片及实物逐步验证。未启动打印，不包含3MF。

本次只加强用户指定的三处承力构造：
1. 外围接触AMS滚轮的环向内加厚，内边界名义半径95 mm，径向宽约5 mm；保留用户源文件的滚动外径、外轮廓及轴向轮廓。
2. 八条从中心筒连接外环的主筋改为宽4 mm、总高3.2 mm（从盘底z=0计）；主筋径向范围43.5–97.5 mm。
3. 中心筒下段向内加厚，名义内半径36.8 mm，下段壁厚约4 mm；斜肩下部同步加厚，在上端逐渐回到原卡扣接口，顶部必要配合不变。

没有新增两条内部承力环。原来的两条环形槽也取消，盘皮为连续0.6 mm薄层，保留每面72个双C的布局。盘面和筋上的双C镂空依原设计切通。
两片总体外形保持约200.02554×200.02673 mm，宽片高40.71506 mm、窄片高34.11305 mm。
纸芯定位键及根部保护区域已单独恢复原几何，标准卡扣、线孔和滚动外轮廓不因加厚而改变。

稀疏填充
STEP只记录外形，不携带填充百分比。与原约1.2–1.35 mm的薄筒、1.6 mm宽的筋相比，现在外滚环、主筋及筒下段具备更大的内部空间，是否实际生成稀疏填充仍取决于喷嘴、墙层、顶底层及层高。检查Studio预览中的墙线/填充，不要只修改填充百分比就假定省料。
盘皮0.6 mm以及接口附近渐薄的区域仍可能全部由墙线或顶底层组成。加粗再稀疏填充并不保证比原薄壁方案更轻。

验证
两片冻结网格均为封闭、法向一致、单一连通体，每条边恰好邻接两个三角面。极微面清理容差1e-6 mm，体积变化小于5e-6 mm³。

边界

未完成本版本的实物1 kg承载、长期PETG蠕变、卡扣反复锁合或AMS动态运行验证。其他受力报告仅在注明几何版本和假设一致时才适用于本版。几何有效不等于已证实安全承重。
