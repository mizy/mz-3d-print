# Chanel A：模型内薄径向斜膜 + 自支撑窗顶

## 修改与参数
在四个开窗中，从完整内导管到外筒增加一体薄斜膜，并把窗口顶本体的下表面改为同一解析锥面；不是仅挂一片悬空斜板，也不是打印后拆掉的树状支撑。默认斜面相对水平50°、竖向厚1.1mm（法向约0.707mm）、四个±36°扇区、根部重叠0.2mm。外侧窗顶仍宽35/窄22mm，窗宽42，四桥及相位不改。

可编辑light_parameters.json中的hub_windows：roof_angle_deg、web_vertical_thickness、web_half_angle_deg、web_join_overlap及窗口尺寸；原盘、logo、A槽与官方配合参数继续保留。非法半径/高度/扇区覆盖明确报错。允许区间不是全范围打印认证；variant.json的55°/1.2mm/37°已实际构建、STEP回读及闭网格验证，但未承诺该变体同样无需支撑。

运行：`python build_light.py --config light_parameters.json --output output`。源模块只用原生草图、旋转、锥/柱面与布尔，不依赖运行时STL或BRep。底部斜面与薄膜共享同一个原生锥面，避免独立近共面构造产生合并问题。STEP只保留几何，不自带Python/JSON参数树。

- 完整内导管、锁口/上套、四桥、定位键、盘/主筋/logo/A槽等15保护区布尔差为0。新膜有意占用原内外筒间空腔，不再以整个空腔不变作承诺。
- H72/70/68 θ51，H66.4 θ51/8实际交叠为0；H66.4 θ3/0仍分别约4.204519/0.368554mm³，与原官方止退局部交叠一致，无新增装配干涉。不是弹性越障或最终卡响认证。
- 新材料不超外筒wide R40.85、narrow R40.65包络：z≥8外圆柱外体积为0，所有新增膜最低z分别≥25.764/8.712；更低区域/原键及底boss另已验证未改。纸芯内径约82mm的社区粗测不是官方公差或用户实物，未据此宣称纸芯适配；实际尺寸、缺口、跨窗变形仍须检查。
