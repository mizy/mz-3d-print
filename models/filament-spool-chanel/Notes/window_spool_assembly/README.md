# 最新开窗轻量版：实际 STEP 数字装配检查

## 结论
109个离散刚体姿态已计算。轴向H72→66.4、θ51°插入，再在H66.4将θ51→8°旋入保留区，所有采样姿态交叠体积为0。**这不是最终卡响锁紧已通过，也不是连续运动/弹性接触仿真。**
固定H66.4继续8→0°，7°出现很小交叠，采样峰值在3.25°为4.243371mm³；名义0°终态仍有4处合计0.368554mm³。3°为4.204519mm³，与官方原STL独立积分约4.196764mm³一致；0°官方约0.364201mm³。位置集中在原止退凸点/卡环，不是此次外筒开窗新加的碰撞。它提示实际过程涉及弹性或更复杂接触运动，未计算变形、扭矩、摩擦、疲劳，不能称合理即安全。
θ8°时沿轴拉到H66.5，交叠1.132996mm³；H67为33.109492mm³，说明几何进入轴向保留区，不代表承载能力。过压到H66.3出现17.307002mm³止挡交叠，不能继续刚性压入。错误入口H70、θ45有2.497411mm³交叠，不能任意按45°直插。

## 几何与坐标
输入是实际项目Models/ChanelLight/CHANEL_PARKING_A_WINDOW_LIGHT_TRIAL.step，SHA256 aebd14b1a16cb334717231dbe5325379227dd089aa0515e8a4cdc158a85b9dd5。先去除两半并排展示的X偏置；wide保持，narrow=Rz(θ)·Rx(180°)·局部坐标+(0,0,H)，不是镜像。
H66.4由wide止挡40.7+narrow肩25.7推导，不把官方STL源文件摆放间距67.4当装配。角度是此CAD坐标系的数值，不是厂商标注的用户操作刻度。插入间隔0.2mm，落座旋转1°；止退区加密0.25°。有限离散采样不保证两采样间完全无碰撞，也未包含偏心、倾斜、打印误差。
外套圆柱配合名义径向差39−38.9=0.10mm（直径差0.20），不是实物间隙保证。新窗模型完整内导管、卡口及上配合区已在前一轮布尔差集核实保持，但外筒开窗使刚度/纸芯支承改变。

## 纸芯：没有编造尺寸，也没有虚报通过
官方安装页要求纸芯缺口对准wide键，再将窄半旋转到卡响，之后按官方顺序移除绑带：
https://wiki.bambulab.com/en/general/swaping-new-filament-with-bambu-reusable-spool
官方页/附件及现有项目均未找到真实纸芯内径、外径、长度、缺口尺寸或公差，故本次**未构造一个假设纸芯实体冒充实际附件，纸芯实体干涉检查尚未完成**。
已知料盘主体wide OD81.7、narrow81.3mm；局部键到R43.7，底boss另随轴向变化。这些不是纸芯尺寸。给定实测纸芯内径D后，主体名义径向差才可算(D−81.7)/2和(D−81.3)/2；仍须核键缺口、端面与纸芯外径/长度。
窗口中高段剩余外圆周支承覆盖约31.25%/30.88%，不等于承载下降比例；纸芯跨窗变形、松线卡入、孔边和支撑残留必须实测。
需要补充纸芯内径、外径、长度、缺口宽/深及测量来源。提供paper_core_measurements.template.json，未知均null；paper_core_check.py已确认会拒绝缺失数据，不生成假纸芯。实际数据提供后，才可构建理想同轴带矩形缺口圆筒并做干涉检查；纸材柔性和粗糙度仍不在模型中。
