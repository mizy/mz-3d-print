# v6 数字装配检查

## 实际保存
`Models/Assembly/CHANEL_v6_ASSEMBLY_LOCK_ZONE_10deg.step`，两个独立有效实体，25,604,196字节。输入仍为配合尺寸有小幅改变的v6候选，v5和未组装v6原件保持不变。

## 姿态依据
- wide筒口止挡面z=40.715057373；narrow肩部止挡面z=25.7150566，二者环面有径向重叠。
- 因此盘底基面落座距离H=66.430113973mm；并非凭外观估计间距。
- 对齐拟合筒轴（wide xy=-0.0273430863,0.0010603425；narrow xy=0.0015810415,-0.0274228517），而不是简单对齐盘的包围盒中心。
- 窄片变换：移除自身筒轴偏置 → Rx180° → Rzθ → 移至wide轴与高度H。
- 可通入口约θ50°–53°附近，选51°直插；落座后沿减角方向转到10°。
- 10°是锁止/轴向保留区内的候选姿态，不是已确认精确硬止挡或弹性卡嗒。6°存在明确干涉，7°也出现极微交叠，故不取极限角。

## 已通过的几何检查
- 完整两半的BRep布尔交集：落座10°、落座51°、H+2mm/51°均为0实体交叠体积，布尔结果有效。
- 落座10°不转回，仅外拔0.1mm，则完整模型产生约1.064mm³交叠，支持此姿态有卡口轴向保留；并非“可以直接拔出”。
- 组装STEP已导出并回读为两个有效实体。
- 实际v6锁管径向包络筛查：高度截面间隔0.025mm、极角射线0.1°；沿51°插入按0.05mm取姿态、落座旋转按0.5°取姿态，共185个姿态。最低采样径向余量约0.13026mm。
- 包络来自v6真实BRep的三角化，仅用于测量筛查，没有把三角面写回制造STEP。CadQuery网格参数0.003为相对偏差参数，并非已证明0.003mm绝对误差界。

## 限制
径向余量不是三维全局最短距离。精确全局最短距离计算未完成，不能报告为已测值。离散姿态/截面不是连续扫掠体无碰撞证明，也没有自动分析弹性变形、摩擦、打印误差、磨损或材料强度。止挡贴合处距离本来可为零，不能简单以“全模型最小距离为零”否定装配。

因此这是数字装配候选与可行路径的证据，不是实物试配/承载认证。v6原先孔/轴的0.008/0.005mm名义改变及潜在净空减少限制依然有效。
