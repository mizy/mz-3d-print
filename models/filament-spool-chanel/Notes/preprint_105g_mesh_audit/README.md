# 105g STEP 与当前 Studio 网格只读核对

原 STEP 未改，用户当前 Studio 界面与项目未改。新增只有本报告，不新增交付模型。

实际 STEP 回读 2 有效实体，每个 1 壳；宽 9046 面、窄 7712 面。两片中心 x±110.013，单片直径200.026，总展示宽420.052。必须拆为独立对象、每片单独放盘，不能同比例缩小整个模型。

独立 OCC 三角化 .01/.1 后，双精度宽半1429439三角、93开放边/0非流形边，窄半497718三角、0开放边/0非流形边。CAD有效不能推导显示网格闭合。与当前 Studio 52开放边数量不同但位置同为宽半锁口z32.4..36.2。独立代理另查原Studio开放边极近似重合；微米级数值缝仍是拓扑缺陷，不应直接忽略。

直接取当前Studio原XML三角拓扑（wide261066、narrow202750），仅Z平移落床并使用原105g低料试验模板，独立CLI目录分别试切，未改源XML或UI。两片都 return0 / Success：宽54.779312g、窄50.052475g，共104.831787g，差于原105.269608是三角化输入不同，不应当作几何减重。两个结果均有1处无法取得支撑的悬垂警告，需逐层预览检查。模板对象标签都叫original_lower_skin04_wide，half=0为宽、half=1为窄，以原XML与高度区分；标签不代表窄片误用宽几何。

切片成功不能证明开放边已修复或局部路径完整。建议先对开放边局部接缝作副本修复、验证闭合/体积和位移，再重新预览锁口层、支撑与桥接，不自动覆盖保留STEP。

废弃尝试：为切片经二进制STL中转会量化到float32，产生额外非流形/退化，本次已停止该流程，不用其切片作结论；上述独立原网格计数是STL导出之前双精度结果，正式副本试切采用原Studio XML而非STL。

## 悬垂/桥接预览层级
CLI警告没有给出区域坐标，不应将任意Overhang wall直接等同唯一失败支撑区域。Gcode标注的悬垂墙层：两片0.6mm；宽另22.2mm、窄另24.2mm。桥接标注层：两片0.6与3.2mm；宽15.8mm、窄14.2与24.2mm。相邻0.8/16.0/14.4仅极少路径点，可能是特征切换残留。建议优先预览第3层盘皮与筋/筒根，再检查外环顶层、肩与锁管根部。overhang_paths.json是按Gcode特征与层高筛查，不是切片器告警区域ID；未完成唯一告警位置定位。
