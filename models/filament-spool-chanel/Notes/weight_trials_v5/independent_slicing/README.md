# 两半约100g独立试切

Bambu Studio02.09.01.70，用户当前Jucoole PETG+密度1.27；喷嘴0.4mm、层高0.2mm。**0.4mm盘皮指Z厚度，两层，不是线宽。** 实际外墙0.42、内墙0.45、顶面0.42、内部实心0.42、稀疏0.45、首层0.5、支撑0.42mm。

当前用户原v5宽半自动备份精确复切61.837g；窄半由v5原生BRep独立显示网格化后57.940g。宽半用同样网格流程重切62.242g，较用户Bambu导入网格差0.405g。因此几何候选必须与同网格流程基准比较，不把网格误差冒充减重。

## 比较（两半单独切片的总耗材相加，g）
|v5几何|原设置|低料试验设置|
|---|---:|---:|
|默认（同网格流程）|120.182|113.298|
|仅下筒内半径38.5|119.079|113.357|
|下筒38.5+盘皮0.4|111.235|105.271|
|**保留原筒壁，仅盘皮0.4**|112.254|**105.270**|

原设置：墙2圈、顶5层且1mm、底3层、稀疏10%。低料试验：墙2圈不变、顶3层且0.6mm、底3层、稀疏5%。全部保留确保垂直外壳厚度enabled、自动树状支撑、自动边缘；使用当前用户其余设置，不改变原UI。

最终优先候选为`Source/weight_trials_v5/presets/original_lower_skin0.4_keep_rib_total3.2.json`所对应原筒壁+0.4皮版本（实际配置以构建effective_parameters.json为准）。筋总高3.2、脚1.4mm、锁口与外套配合不变。宽55.021503g+窄50.248104g=105.269608g。窄半支撑/界面约3.420645g，宽半无支撑；扣支撑约101.848962g，仍可能含少量自定义路径。**不是电子秤净重，也不保证机器清嘴、校准等全部废料均计入。** 这里不包含新增干燥模块或干燥剂。

只做薄下筒没有实际省料收益：窄半3.8<z<14mm的稀疏填充由约0.918g减至0.065g，却新增密实填缝约1.425g；该高度带总6.370g→7.144g。实体体积缩小不保证切片耗材减少。保留原厚下筒与薄筒组最终质量仅差0.0011g，没理由仅为减重选择薄筒。

## 限制
这不是承载认证。0.4mm盘皮只有两层，抗撕裂/翘曲/侧弯风险，5%填充和3顶层仍需打印测试。保留筋、环、锁口并不证明整盘能承受特定重量。未修改原默认文件或用户当前UI。所有3MF与Gcode仅为/tmp/chanel_100g中的内部试验容器，不作为用户交付；此目录只归档报告/代码/日志。几何有效性由构建报告提供，试切返回码和SHA详见JSON。
