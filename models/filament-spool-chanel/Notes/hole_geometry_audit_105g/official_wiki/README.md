宽/窄附件与用户 Downloads/bambulab_spool_{wide,narrow}.stl 逐字节一致。SHA 记录于 measurements.json。

官方文件沿 X 轴。用半径>95mm盘缘和逐截面最大半径独立确认外侧方向后，wide z=33.70000076293945-X；narrow z=X+33.70000076293945。所有 z 从各自外侧盘面起算。早期临时脚本曾反向，已纠正；这里所有归档结果都是纠正后的版本。

数字由720方向射线首次边界交点的2倍半径中位数报告；圆孔附近可近似直径，非圆锁口不能据此作为通规直径。原STL有网格离散及小偏轴，故不解读百分之一毫米差值为公差差异。当前105g数据引用上级目录已完成的实际STEP回读量测。

官方wide z32.5/34的轮廓含锁齿，2倍半径包络约59.79..62.80，不是纯圆。z38/40仅剩外套筒，孔约78，并不意味着外侧支承孔78。

结论：原用户spool2.1在本次抽查的下段支承/导向轮廓与官方附件近似一致；105g重建下腔/台阶不一致。恢复应针对完整内导向管、外侧支承环和过渡/倒角，不是把整个空腔灌成厚壁。未修改几何、切片设置或UI。
