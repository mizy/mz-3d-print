**结论：当前模型未保持用户原STL的完整通轴导向/支承结构。不能继续作为原孔径完全兼容版打印。**

## 结构解释
当前最外口薄段wide约Ø79、narrowØ78.8，接下来下腔Ø73.6；原两半倒角后的支承孔均约Ø55。原宽半在z约3.7..8逐渐扩至Ø62.8，原窄半Ø55贯穿至z33附近，然后末端有扩口倒角。当前宽半Ø73.6保持到约z14.15才斜收口，窄半保持到约z12.55才斜收口、约z24后才出现Ø55；窄半顶口倒角还被直孔替代。

原STL在z3..20有独立内导向管：wide外R约33.3，内R27.5→31.4；narrow外R约29.7，内R约27.5。外围另有外套，中间为空腔及局部连接。当前重建下部换为大空腔和斜肩，缺失这段原内管，不是简单显示比例问题。

## 恢复方案（尚未改模型）
1. 按原STL恢复内导向管全轴向轮廓：下端倒角、Ø55支承段、宽半过渡至Ø62.8、窄半上端倒角。
2. 恢复盘外侧与内管相连的支承环；与既有加厚外筒、筋的连接单独设计/验证。
3. 不能直接把hub_lower_inner_radius从36.8改27.5来灌实整圈，否则改变原双层筒空腔并浪费材料。
4. 对原STL全深度截面、两半装配、通轴净空及新的切片质量重新验证；不再提前承诺105g。

此前锁口对照主要验证两半上部旋锁和外套，不能推论整个中心轴支承孔均保留。修复3MF只消除网格接缝，不修复本结构差异。

本报告仅实测所提供模型，**不是拓竹官方标准尺寸或全系列兼容认证**。未改STEP、未改用户UI、未启动打印。原STL和STEP的SHA详见measurements.json。
