# 独立装配运动推导（非精确装配验收）

基准：原冻结交付 STEP 的只读测量网格；本组不是 v6 候选布尔干涉结果。

## 同轴姿态
将 narrow 先平移 -cn，再绕 X 翻转180°、绕 Z 旋转 theta，最后平移 cw+(0,0,H)。cw=(-0.0273430863,0.0010603425)，cn=(0.0015810415,-0.0274228517)。角度以 +X 起逆时针，narrow 方位 phi 映成 theta-phi。默认两个盘基面 z=0 间距 H。

wide 口顶 z40.715057373、半径39..39.75；narrow 止挡肩 z25.7150566、半径38.898..39.65。两环径向重叠，故完全落座候选 H=66.430113973 mm。H更小应出现肩口干涉。内锁管首次接触约 H71.37801；外颈开始插套约 H68.630114。这是轴向几何依据，不含打印公差/弹性。

## 粗筛线索
原件极坐标截面筛查采用0.25°极角、1°旋角、0.1 mm高度采样。点列极角插值不是精确射线相交，不能排除漏过窄小干涉。报告中的0.01 mm阈值仅用于识别角窗口，不是验收公差。

H71入口49..53°；H70和69仅50..52°；H68为48..52°；H67为40..52°；H66.430114为7..52°，另104..135°静态窗口。合理序列：theta约51°直插，接近落座后减小theta旋入保留区；推测终点约低角边界，必须由v6精确交集/接触定位，不应把最小干涉角当锁止。第二静态窗口不证明存在连通插入路径。

## 必须独立核实
主代理对v6实际候选检查：入口到落座连续路径、旋转路径、停止角两侧穿透、锁止后正向拉拔是否被挡、反向解锁是否可退出。精确BRep交集须同时核实有效性/实体数/体积，不只isValid；零交集可能是失败输出。有限采样和刚体无碰撞不证明连续运动或打印装配，尤其候选改变导向面约0.005/0.008 mm，不能称无损。
