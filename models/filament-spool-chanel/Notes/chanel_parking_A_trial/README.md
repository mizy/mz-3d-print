# Chanel 官方中心派生：A 停线槽 + 保守镂空减重试验

基于已还原官方完整中心的轻量双 C 版本，不是旧105g体。仅作待试打候选，原件保持不变。

## 再生
安装 requirements.txt；在本目录运行：
`python build_light.py --config light_parameters.json --output output`
生成 CHANEL_OFFICIAL_LIGHT_PARKING_A_TRIAL.step，一个STEP含宽、窄两个独立有效实体。
全套独立Python/JSON参数源不需运行时STL或BRep。STEP仅几何，不自带源特征树。

## 修改
- light_flange.logo_scale=1.06：扩大双C镂空；保留logo_scale=1.0原方案8条主筋的材料交集，扩大孔不得进一步削筋。盘皮仍0.4、筋宽4/总高3.2、外环宽5，完整官方中心/卡口保留。
- parking_slots：原四孔保留，在selected_sx一侧两个孔接切向10mm停线槽，另两个孔原样备用。槽直径2.1、中心高度2.15、喉宽1.7、顶口2.1。局部下底名义1.10mm。内侧有少量唇口，不增加外径或厚度包络。
- 槽用于停放耗材尾端；正常AMS送退丝必须先释放。名义1.75耗材与1.7喉的夹持依赖材料和打印公差，尚未实测，不能保证夹持力或无挂丝。更松的喉口可调整，例如1.8；实际变参例见variant.json。
- 通道6..12mm、直径1.9..2.4mm、喉口至少1.6且不大于通道直径、底厚至少0.9mm；仅代码允许区间，不是整区间可靠性认证。非法组合报错。

## 仿真报告适用性
读取用户指定 spool-axial/upright/report.md 及独立审计：它是旧105g几何、66.43mm/10°绑定锁环、均匀E2GPa线弹性、4处弹簧托轮、静载约10.81N。自重以约101.85g等效密度校准，但刚度仍全实体；未计打印稀疏、层间、蠕变、实际扣合、退丝拉力。细化沉降仍变10.7%；小线性求解残差不等于物理认证。P95不覆盖局部尖峰。
因此只据其载荷传递趋势保留中心、主筋、滚动轨与0.4盘皮，不把它当作本改版强度通过。槽削去内侧滚环材料，连续外圆没变也不代表环承载不变。必须小样夹持、实物试配及承载验证。官方原卡口刚性交叠仍原样保留，不推断弹性越障安全；不使用打印料盘烘干。

## 本轮验证结果
最终STEP回读2有效实体；网格均0开放/0非流形；同配置CLI切片合计119.071098g，比119.632122g仅少0.561024g（0.47%），不是大幅减重。切片返回无warning_message不等于实物强度或夹持通过。
核心、原主筋、外圈滚动表面布尔差为0；但槽处环内侧材料有损失。变参（logo1.04、槽长8、喉1.8）也2有效实体且网格闭合。保存后的独立源码已实际再生，几何面数/体积一致。
