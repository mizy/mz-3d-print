# v6 阶段优化候选，不替换默认 v5

本目录只完成一类简化：把锁管的重复碎面基底改为整体圆柱或导槽拉伸，保留复杂锁齿曲面。**没有把整个锁口重建成少量设计特征，齿带仍有较多分界。**

这是近似优化，不是无损合并：
- narrow 基底半径使用 29.705×k mm，比名义 29.7 增加 0.005×k mm。
- wide 导槽孔轮廓向内偏置 0.008×k mm。
- k=lock_reference_bore_radius/31.4。两者可能使径向配合净空合计减少约 0.013×k mm，实际接触区未必同时生效。未做装配/实物试配，不能把这些基底说成非配合面。
- 默认体积略有增加，不是单纯隐藏边线。实际变化和采样误差须看候选验证报告。
- 另一条恒截面平台替换研究在 narrow 融合失败，没有合入本目录。没有通过容差放大或忽略零实体来假装成功。

继续使用与 v5 相同的 parameters.json 输入；源码会从原生控制截面再生成，不读取网格或固定的成品 STEP。新输出名 CHANEL_SOURCE21_parametric_v6_candidate.step。所有范围仍仅是输入限制，并非每个组合都验证。

以下为继承的 v5 参数使用说明；“v5已验证”只指 v5，v6 具体通过范围以独立报告为准。

# CHANEL 料盘 v5：可再生成的参数工程

**修改 `parameters.json`，再运行 `rebuild.py`。这个 JSON 是实际输入，不是生成后写出的说明文件。**

v4 与原网格/旧 STEP 全部保留。本目录不读取三角网格；圆、直线、圆弧、旋转面和配对放样产生原生 CAD BRep。卡口变化段由原件拟合的圆弧/直线截面控制；这不是把三角面封装成 STEP。

## 使用

环境：Python 3.11，见 `requirements.txt`。当前已用 CadQuery 2.8.0 验证。

```sh
python rebuild.py --config parameters.json --output build_output
# 用另一个配置，不改默认文件：
python rebuild.py --config presets/lock_dimension_test.json --output my_test_output
```

输出一个 `CHANEL_SOURCE21_parametric_v5.step`，含可分别选择的 `wide_half` 和 `narrow_half`，另存实际参数、两个 BRep 及验证报告。导出后自动回读，要求两个实体都有效。默认两半平铺，不是装配姿态。装配间距随盘外径变化。

STEP 是几何交换文件，**不携带这套 Python/JSON 的特征树或参数界面**。要继续快速调尺寸，保留整个源码目录。直接编辑 STEP 的能力取决于使用的 CAD 软件。

## 参数（全部长度单位 mm；radius 为半径，直径需乘 2）

| 参数 | 默认 | 作用与联动 |
|---|---:|---|
| rolling_outer_radius | 100.013 | 外滚环半径，默认外径 200.026；联动环内缘、孔位、盘皮外缘、筋外端、Logo 行半径、导出摆放间距 |
| rim_radial_width | 5.013 | 环径向宽度；增加时向内加宽，盘皮/筋/Logo 区域同步移动 |
| rim_height | 3.615 | 滚环轴向高度；孔与孔旁加强垫同步贯穿 |
| skin_thickness | 0.6 | 盘皮厚度；筋底随之抬高，脚部连接高度同步，Logo 切削自动贯穿 |
| rib_width | 4 | 主加强筋宽度 |
| rib_height_above_skin | 2.6 | 高于盘皮的筋高；总高=skin_thickness+该值 |
| rib_count | 8 | 均布主筋数量；长度自动从筒脚连至滚环，不再手填 |
| logo_scale | 1 | Logo 整体 XY 比例；不缩放切削深度，默认各行仍保留 v4 比例 |
| logo_rings | 见 JSON | 每行 fraction 为盘皮内外缘间的径向比例；count 是数量；relative_scale 是该行单独比例 |
| hub_outer_radius | 40.85 | wide 下筒主外半径；narrow 比它小 0.2。上下外套、筒脚、定位键和盘内边同步。两半外套配合面同步平移半径，不保证和旧打印件混配 |
| hub_lower_inner_radius | 36.8 | 下筒内腔半径；与斜肩底部联动，减小可加厚下筒壁。不是中央穿轴孔 |
| sleeve_wall_extra | 0 | 外套筒额外增厚：wide 向外加厚，narrow 向内加厚，不向两半套筒互配间隙侵占。wide 上套外半径随之增大 |
| shaft_bore_radius | 27.5 | narrow 中央穿轴孔半径，默认孔径 55；内锁管及斜肩内缘同步。wide 卡口孔不受此字段控制 |
| lock_reference_bore_radius | 31.4 | wide 基准卡口孔半径；按与 31.4 的比值共同缩放两半锁齿/导槽的径向尺寸，关联管底、肩和桥。不是只改一个圆孔 |
| lock_axial_scale | 1 | 两半中央筒/锁口/肩/桥/定位键的轴向比例；盘皮/滚环/主筋另行控制 |
| wide_lock_wall_thickness | 1.9 | wide 内锁管外侧壁厚，驱动外管径、肩顶和桥内端，不改变内齿轮廓 |
| bridge_width | 1.2 | wide 内锁管到外套的四条连接桥宽度 |

## 配合与参数限制

- 默认重建用于回归 v4，不承诺 v4 与原网格每点完全一致。原先独立截面最大采样偏差约 0.029 mm 的限制仍适用。
- 想沿用已打印的另一半时，保持 `hub_outer_radius`、`lock_reference_bore_radius`、`lock_axial_scale` 不变；其他改动也要检查实际装配空间。
- `lock_reference_bore_radius` 共同径向缩放锁口，**间隙也会随比例变化**，不是单独的恒定间隙补偿器。改锁口/套筒尺寸应两半一起打印试配，不承诺兼容旧件。
- 内置有限输入范围及最小壁厚/间距检查；缺字段、多字段、非数值、非法枚举均报错。范围只用于拦截明显不合理输入，**不等于范围内所有组合都已验证**。合法输入也可能因 Logo 相交、断筋或复杂布尔失败而明确报错。
- 加厚模型只证明可生成有效几何，不证明强度。稀疏填充由切片软件决定；层高、壁数、材料、打印方向与填充率会改变承载能力。未进行有限元应力求解、疲劳、冲击、实际载荷或实物装配验证。
- 本工程没有声明“任意面或任意结构都可一个参数改变”。当前命名参数覆盖盘、Logo、主要筋、环、筒和卡口的上述需求；固定的小孔直径、倒角细节、定位键轮廓与锁齿局部形状仍由源码/截面控制数据定义。如需要独立改这些局部细节，应编辑相应源几何并重新验证。

## 文件

- `config.py`：真实配置读取、输入范围及派生量
- `body.py`：盘面、Logo 排布、筋、滚环、孔、筒、肩、桥
- `motif.py`：双 C 图案的原生圆弧/切割和连接细节
- `lock.py` / `native_loft.py`：原生截面变换、匹配放样、缝合与实体检查
- `native_lock_sections.json`：默认卡口圆弧/直线控制数据
- `rebuild.py`：完整构建、单 STEP 双实体导出与回读
- `presets/`：具体变参测试输入；是否通过看对应验证报告，不能仅凭文件存在判断
