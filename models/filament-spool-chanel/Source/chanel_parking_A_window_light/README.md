# Chanel A 停线槽 · 外筒开窗减重候选

此版在已恢复官方关键配合的119.14g A槽版上，仅对两半外筒四桥之间开四个圆角窗。原件另存保留。

## 保留与改变
保留完整连续内导管（不再删掉中心轴向导向支承）、轴孔上下轮廓、卡口、止挡、外套实际插入段、四条完整桥、定位键、盘面/主筋/滚环、双C装饰和A停线槽。
外筒中段不再是官方完整圆筒：成为四个柱段加上下环的框架，纸芯接触面积减少，径向椭圆化/弯曲刚度和夹入松散耗材风险改变。不能只因为配合面没动就认定使用性能不变。尤其不承诺可直接在无纸芯条件下绕线或兼容任意纸芯。

A槽仍仅用于停车收纳；正常AMS送退丝前释放。已有A槽局部滚环截面削弱与夹持未实测的限制不因本轮变轻而消失。

## 原生参数化
运行 `python build_light.py --config light_parameters.json --output output`。
模块仅用原生圆弧/线草图、旋转、圆柱/圆锥、圆角与布尔特征；没有运行时STL或BRep依赖。STEP是双独立实体几何，本身不含JSON/Python参数树。
新增 hub_windows 参数：四窗相位45°、窗宽、圆角、宽/窄窗底/顶、内导管保护半径、切刀深度。内导管保护半径须至少比当前内导管外径半径大0.2mm；窗顶须满足上配合保留带；非法组合明确拒绝，不静默放行。
只有已实际构建/切片的参数组合被验证，不代表整个允许区间可用。窗口用同轴圆柱保护核心，不用局部X平面截断，避免窗侧缘残留假薄壁。

没有对本开窗版求解新FEM，没有实物承载/卡持/AMS运行认证。改造使外筒成为框架，不再是完整官方筒壁；纸芯支承、径向刚度、支撑清理和松线卡入风险必须实际验证。为减最后约3g不再盲目削盘/筋/滚环。
