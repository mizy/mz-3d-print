# idea-028 云朵托架 · SKADIS 洞洞板手办搁板

> 原创设计，2026-11-07 实打验证，2026-11-09 归档。本目录是这件设计的**唯一母版**：
> 原始建模（STL）、四色分盘 3MF、上传文案与实测参数都放在这里。

## 需求

在 SKADIS 洞洞板上放 2–3 个盲盒/小手办，要一个云朵形的小搁板：

- 背面两只 SKADIS 挂钩，挂上去就能用，不打孔
- 底盘有前后挡边，手办不会往前滑出去
- 装饰件（彩虹拱、月亮、星星）可拆可选，能分色
- 主体竖着打印，尽量少支撑

## 四色分盘 3MF

`3mf/cloud-shelf-skadis-4plates.3mf` 是 Bambu Studio 工程文件，按**实际打印颜色**分 4 盘：

| 盘 | 内容 | 颜色 / 耗材 | 对象 |
|---|---|---|---|
| 1 | 主体 | 奶油白 PETG `#FABBCB` | cloud-shelf-main |
| 2 | 背板 + 前挡板 | 灰 PETG `#898989` | back-panel, front-panel |
| 3 | 云朵 ×2 | 白 PETG `#FABBCB` | cloud-a, cloud-b |
| 4 | 拱条 + 星月 | 黄 PLA `#F7D117` | rainbow-arc, moon, star-large/medium/small |

工程里的对象是**逐件独立**的，不是合并网格，可以在 Studio 里单独挪动。
流程统一为 0.20 mm、2 墙、8% 陀螺填充；实际打印时主体可改回 0.28 mm、装饰件改 0.16 mm。

**耗材提醒**：机上现在（2026-11-09）AMS 是白/黑/灰/浅蓝 PETG，没有黄色 PLA。
第 4 盘要打，需要补一卷黄色 PLA，或在 Studio 里把该盘映射成现有的黄色系耗材。

3mf/                  四色分盘工程 + 10 件全排一盘的原始 3MF
build/                可重跑的 3MF 构建脚本 + 工程参数模板
docs/                 本文件 + MakerWorld 上传文案
preview/              上色渲染图、主体四视图

## 重跑

```bash
python3 build/build_plates_3mf.py
```

脚本会读取 `model/plate-stl/`，把每个分盘网格拆回独立零件，按颜色写入 4 个虚拟盘，
并复用 `build/template-project_settings.json` 里的 P1S 工程参数。
