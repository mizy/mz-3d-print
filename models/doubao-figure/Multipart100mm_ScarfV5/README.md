颜色分界依据实际的原始带纹理模型。V4 脖子上误归为肤色的外宽卷边已移除，新肤色头的下颌下仅有正常皮肤过渡和连接用隐藏榫，保留旧版下端阶梯定位榫。上卷边重建在独立红围巾上；并按肤色头插入轨迹给围巾内口留了让位。眼睛、嘴唇仍沿用手涂方案。预览是实际模型的类别着色，不是打印好的照片。

## 干装顺序

1. 一体双鞋插底座，裤子从上方套入双鞋。双手先从下方插入相应袖口，再把卫衣连双手一起套到裤腰。
2. 围巾尾巴向前，从衣身的正前上方斜向后下方推（后退约 1.8，下降 1），而非垂直压下。
3. 把一个肤色头从发帽右前下方斜向后上和左微移（往后 1，对上 0.65、往左 0.25），对上原定位。**没有另装颈部这一步。**
4. 整个头部直向下插过围巾到衣领。干装后可以少量点胶。

九件独立闭合、Bambu Studio 无切片回读；用 0.10 mm 步长重新检查装配路径。未切片、未实物试装。请自行预览支撑、着地和榫孔的清理，切勿混用 V4 的颈件或红件。
