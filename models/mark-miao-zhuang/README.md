# 苗壯 印章（maker's mark，可复用到任意模型）

给自家打印件打标的个人印章：小篆「苗壯」+ 简化的白菜叶，**凹刻**用（往里陷，不凸起）。

## 资产

| 文件 | 用途 |
|---|---|
| `seal-raw.png` | AI 原图（CodeBuddy，保留边缘），以后要重新出图/改造型用这张 |
| `seal-mark.png` | 二值图，`engrave_mark.py` 直接吃这张 |
| `seal-tool-16mm.stl` | 预制刀具，长边 16mm、深 0.5mm，Bambu Studio 里当**负零件**用 |

成品尺寸：**10.9 × 16.2mm**（长边 16）。笔画转成几何后 0.5–0.8mm。

## 用法一：脚本（推荐，3MF 保留全部切片参数）

```bash
python3 ~/.cah-data/skills/shared/3d-print-ideas/scripts/engrave_mark.py \
  --model 目标.3mf \
  --mark ~/.cah-data/skills/shared/3d-print-ideas/models/mark-miao-zhuang/seal-mark.png \
  --out 目标_已刻.3mf --size 16 --depth 0.5 --face bottom
```

- `--size`：印章长边 mm（12 小巧 / 16 默认 / 20 醒目）
- `--depth`：凹刻深度，0.4–0.6 合适（层高 0.2 时落在 2–3 层）
- `--face bottom|top`：底面会自动镜像（翻过来看是正的），顶面不镜像
- `--at dx,dy`：偏离模型 XY 中心的位置
- `--fatten 0.15`：笔画外扩，0.4 喷嘴必须留这个量，否则细线打不出来

## 用法二：Bambu Studio 负零件

1. 把 `seal-tool-16mm.stl` 拖进工程，右键 →「作为负零件（Negative Part）」
2. 它的 Z 跨度是 0–0.9mm，**整体下移到 Z = -0.4mm**，就是凹刻 0.5mm
3. 模型本身保持底面朝下；印章已在 STL 里做镜像，不用再翻

## 2026-11-12 修正：方向 bug

旧的 `engrave_mark.py` 把 PNG 行序直接当 +y（行 0 = 最小的 y），而模型 +y 是朝上，
于是刻出来的印面在「翻过来看」时是 **180° 旋转**的（不是镜像）。实测办法：比较
`seal-mark.png` 各连通块的归一化质心与切出的凹槽屋顶——旧版白菜叶跑到了右上角。

已修：`raster_to_polygon()` 里加了 `ink = ink[::-1, :]`（图片行 0 = 顶部，翻成 +y 朝上）。
刀具 `seal-tool-16mm.stl` 已按修好的映射重建，旧刀具备份 `seal-tool-16mm.pre-20261112.stl`。
2026-11-12 之前的刻章件（含流云花瓶）方向可能都是反的，重打时用新刀/新脚本。

## 设计依据（改尺寸前先看）

- 0.4 喷嘴、0.8 线宽；笔画低于 0.5mm 会打不出来或断成虚线，所以脚本默认外扩 0.15mm
- 印章长宽比 0.7（竖章），16mm 长边 → 10.9mm 宽；想「1cm 宽 × 2cm 高」两种做不到同时满足
- 白菜叶必须是**实心单轮廓**：带叶脉的细线版在这个尺寸下打成一团（2026-11-01 实测淘汰）

## 重新出图时的 prompt（记录，避免重走弯路）

> 中国传统小篆印章设计，正方形印面，细边框。印面内竖排两字「苗壯」，秦代小篆，线条圆转等粗。
> 印面右下角一枚极小的白菜叶标记，与文字留明显空隙、不接触。纯黑白硬边、无灰阶、无阴影、无做旧纹理。
> 白底黑图、图案居中、四周留白 10%。

已知坑：AI 会把细边框画到贴图边，导致裁切时把边框切掉；`seal-mark.png` 是从中裁好并做过二值化的版本，别再从原图重新裁。
