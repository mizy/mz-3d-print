# V10 双高抽屉｜独立试作

标准 V10 不变；本版以实际无导向垫、无胶槽、双局部翻转压扣和前后辅助托沿的标准件为基准。**框架叠层节距 48→96 mm；凸出的定位柱再加 5.8 mm，整层框架最高 101.8 mm。外部占地 180×200 mm 不变。**

- 2.60 mm 平底、下托轨顶 Z10.0 和辅助前后托沿 Z9.80 原位不动；原托盘的 XY 包络 147.90×190.00 mm 不变。内底 Z12.60 到普通侧沿 Z83.50 可用高度约 70.90 mm，较高前后端 Z88.00，端部最大净高约 75.40 mm。节距不是托盘净高。
- 从平底上方 Z12.90 的实际闭合曲线截面增高 48 mm；上部（两端、凹口、签字、止挡面和局部后备托）只平移，不整体缩放。新增长壁段仅往内多加约 0.40 mm，并在两端各用 3.0 mm 渐变接回标准壁。原来有签字的外墙仍保持对应几何，内壁留厚不会保证不翘曲。
- 左右铰链轴中心从 Z43.60 到 91.60，Y97.00，轴孔/卡簧/定位键和两压扣尺寸不变。高侧板重新生成支撑 X 腹板；高后 X 重新生成 5.20 mm 斜撑，不开胶槽。保留后撑 Z≤11.0 mm 原平面、榫、低端锁槽和辅助托沿，后侧孔位保持宽距。
- 新件四种：01 左侧板、01b 右侧板、08 托盘、10 后 X，各一件。共享：09 前梁一件，02/02b 压扣左右各一，03 轴／04 卡簧／05_Mode 定位键各两件，05b 框架转锁四枚。共用件只在 [标准高 STEP](../V10_Prototype/STEP/) 归档一份；[叠层衬套](../V10_Prototype/STEP/Optional_Stacking/)也是共用选配，不计单层 17 件。
- [00 装配 STEP](STEP/00_V10_2X_Locked_Open85_REFERENCE.step) 是唯一双倍高总成参考，展示压扣锁定、抽屉拉出 85 mm；不打印总成。
- 要取出：先空载并往里回推一点，拔两个工作定位键，向后旋两侧压扣进入停放位，插回定位键固定，托住抽屉再取出；装回前先保持在停放位。不得以动作检查替代对实体连接、强度、疲劳、翘曲和公差的试印验证。高屉中重物重心也可能更高，整个柜架仍需独立可靠固定。没有做切片或 Studio 操作。

## 检查和再生

`V10_2X_TEST.json`：准确 BRep 回读实体数及校验，双向锁定及完整释放轨迹、旋转、定位键和叠层接头。止挡／限制抬起均只是几何接触，不是强度认证。标准零件保持实际原始文件，精确字节校验见 `SHA256SUMS`。

参数源默认读取相邻的标准高目录（基准零件、尺寸和 CAD 辅助函数），不重复保存基础模型。修改 `Source/double_height.json` 参数后，在可导入 FreeCAD、Part、Import 的 Python 环境下运行：

```
python Source/build_double_height.py --out /a/new/work/directory
```

STEP 是精确实体交换文件，不含 CAD 特征操作树；Python、JSON 和冻结基准构成参数化再生源。

独立 [双倍高 3MF](Print/V10_2X_Height_P1S_PETG_UNSLICED.3mf) 已包含全部 17 件，开档不需要先加载标准件。四盘为抽屉 1 件、侧板 2 件、框架 6 件、压扣及配件 8 件；工程未切片。

已用 macOS FreeCAD 1.0.0 的无界面 Python 重建并验证完整运动检查；重建的五份 STEP 的实体尺寸和体积与归档件相符。
