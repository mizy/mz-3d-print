# idea-003 内存条 + CPU 展示架 · v3 设计文档

一句话：一块底板 + 一块后仰 15° 的背板，背板前面上下两级斜靠面——**4 根内存条坐下层、3 颗 CPU 坐上层**，
物件正面（内存标签面 / CPU 的 IHS 面）朝观众，纯靠重力斜倚；背板背面两道加强筋把力传回底板。

- 版本：v3（2026-09-28）
- 硬约束：单件外廓 ≤ 250 × 250 × 250 mm（主人打印机尺寸上限）
- 对象：4 × 内存条（带马甲按 42 × 133.35 × 8 mm 取值）+ 3 × CPU（40 × 40 × 5 mm）
- 材料目标：PETG 优先（韧性好，反复取放不易崩口），PLA 亦可

## 2. 结构

```
            ↑ Z
            |  背板（后仰 15°）
   CPU 层 → |  ▨▨▨      ← 3 颗 CPU 斜靠，坐 Z=138 台面，IHS 朝外
            |  ▨▨▨  加强筋 ×2（贴背板背面，高 118）
   内存层 → | ▮▮▮▮      ← 4 根内存斜靠，坐底板面 Z=0，标签面朝外
            |___________  底板 200 × 103 × 6（前伸 20mm 当基座 + 名牌凹位）
             → Y（观众方向）
```

受力逻辑（一句）：每件物件背面整面贴靠板前表面、底棱压水平面 → 坐进一个直角角里，重力把它**压进板**，不靠摩擦；
背板根部埋进底板 3mm，两道加强筋把背板中上段的弯矩传回底板 → 力全部回到同一块底板。

## 3. 参数（要架的东西，改这里就够）

| 参数 | 缺省 | 说明 |
|---|---|---|
| `ram_n` / `ram_w` / `ram_thick` / `ram_len` | 4 / 42 / 8 / 133.35 | 内存条数、宽、厚（带金属马甲 8，裸条 2）、长 |
| `cpu_n` / `cpu_w` / `cpu_thick` | 3 / 40 / 5 | CPU 颗数、边长、厚（含 IHS） |
| `tilt` | 15° | 后仰角；tan15° = 0.27 < μ≈0.30，挡边仍兜底 |
| `ram_tine_d` / `ram_tine_h` | 12 / 16 | 内存分隔牙尺寸（凸出量 = 牙深 − 内存厚） |
| `cpu_tine_d` / `cpu_tine_h` | 6 / 22 | CPU 分隔牙尺寸 |
| `Zp` / `plat_d` / `plat_t` | 138 / 16 / 4 | CPU 台面高度 / 进深 / 厚 |
| `rib_h` / `rib_reach_bot` / `rib_reach_top` | 118 / 20 / 8 | 加强筋高度、底部伸出、顶部伸出 |
| `hex_r` / `hex_pitch` / `hex_cols` | 6 / 18 / 9 | 蜂窝孔半径 / 间距 / 偶数行孔数 |

位宽是派生的：`ram_cw = ram_w + 2`、`cpu_cw = cpu_w + 2`（各留 2mm 不夹）；架宽 `W = ram_n*ram_cw + (ram_n+1)*tine_t`。
收第 5 根内存时把 `ram_n` 改 5 即可，改完 `W` 变 238，仍在 250 内。

| 指标 | 值 |
|---|---|
| 整机重心 | (X 95.5, Y 37.2)，离底板面高 70.1mm —— 投影落在底板内 |
| 估重 | 609 g（塑件 379 g + 4 内存 140 g + 3 CPU 90 g） |

物件自重按内存 35 g、CPU 30 g 估值；实物更重也只是把物件更牢地压进靠板，倾斜方向不变。

## 5. 可打印性 / 切片参数

- **免支撑**：最斜的面是 15°（远离 45° 悬垂线）；加强筋是竖直薄片（两片大面垂直平台）；蜂窝孔只在 4mm 背板内贯通，不啃前表面。
- 打印朝向：按模型原样放平台（底板面朝下），无需旋转。
- 建议切片：层高 0.2mm / 墙 3 道（1.2mm）/ 顶底 4 层 / 填充 15–20%（gyroid 或网格）/ 无需裙边或 brim（底面积 200×103 足够附着）。
- 实际用料：实体 269.09 cm³（PLA 满打 334 g）；按 3 道墙 + 20% 填充 **实测口径约 237 g PLA / 243 g PETG**（`scripts/cost.mjs` 壳层法：表面积 1364.9cm² × 1.26mm 壳 + 20% 芯部），一卷 1 kg 料够打 4 个。
  （早先口头说的「约 150 g」是按 45% 经验系数拍的，偏乐观，已被 cost.mjs 的壳层法取代 —— 这个是 4~6mm 薄壁件，3 道墙占厚度的一半以上，实际密度接近 70%。）
- 配件：底面 4 个坑贴 ⌀12 × 1.5 自粘硅胶垫；名牌凹位贴 120 × 12 标签（如「DDR4 3200 16G」「i5-12400」）。

## 7. v3 相对 v2 的改动（主人 9/28 三条意见）

1. **CPU 挪到内存条上面**：内存条坐底板（下层、Z=0），CPU 坐 138mm 台面（上层）。
   平铺一排要 330mm 超 250，只能错层，上下对调后重心更低。
2. **背部加支撑加强筋**：两道 4mm 竖筋贴背板背面，高 118（约背板 2/3），底部后伸 20 收到顶部 8，
   把「物件 → 靠板 → 底板」受力链在背部连成一体，背板不再是从上到下悬空的薄板。
3. **两侧隔板收短**：内存牙从 v2 的 18 × 50 收到 12 × 16（只比内存前表面凸 4mm、高度刚够分开相邻两根），
   CPU 牙同步收到 6 × 22（凸 1mm）——只把相邻两件分开，不再是两道隔墙。

## 8. 已知事项（如实记录）

- 导出的 ASCII STL 里有 16 个**零面积（三点共线）三角面**，全部落在底板顶面 Z=0 与台面 Z=138 的平面三角化里，
  不贡献体积；watertight 判定（每条边恰好 2 面）不受影响，主流切片器会直接忽略这类退化面。v2 的 STL 没有这种面。
- OpenSCAD 控制台报 `Volumes: 2` 也出现在 v2 上（v2 已实际打过交道的成品），是 CGAL 对含大量贯通孔件的计数口径，
  与网格 watertight / 单连通判定无关——以 STL 体检结果为准。
- **不要用** `--export-format=binstl` 导这个件：二进制路径会把 T 型接点写出 139 条非 2 面边（float32 误差 + 三角化差异），
  切片器虽能自动修，但没必要。用 ASCII。
