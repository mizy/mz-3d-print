# 优先试印：按高度换色的简洁机甲侧饰版

推荐先用本目录，不使用旧版双色方案。这里都是网格试印文件，不是可编辑参数化 STEP。未切片、未装机验证。

## 打印朝向与换色
主体文件已经摆好：原模型无装饰的宽侧面朝下，装饰侧朝上。**保持导入朝向，不要自动旋转或分别居中**。外形约 101.052 × 12.700 × 15.000 mm。

深灰：打印 Z=0 至 14.6 mm。
青色：仅顶端 Z=14.6 至 15.0 mm，共 0.4 mm 厚。

按 0.2 mm 层高、首层也 0.2 mm 的名义几何，最后两层是青色，主体只需从灰换青一次；实际换色层由你切片预览确认。没有同高度混色的图案，不需要沿每层反复换色。按钮可以另外整颗用橙色打印，不在主体上增加橙色层。

## 选哪个文件
- 最省事：`BODY_ALL_SINGLE_COLOR.stl` 是完整连续主体。导入后按高度换色；也可直接单色打印。
- 自动识别分色：`BODY_HEIGHT_COLORS_GEOMETRY_ONLY.3mf` 是保持共同位置的灰、青两部件几何容器，**不是打印机切片工程**。若软件忽略材料颜色，请手动指定。
- 手动分部件：`BODY_GRAY_TO_HEIGHT.stl` 和 `CYAN_TOP_LAYERS.stl` 作为同一个对象的两个部件导入，保持共同坐标。
- `BUTTON_PRINT_TWO.stl` 打印两颗，原作者按钮仅平移到板面。按钮朝向仍可按你自己的切片判断调整。

## 已做几何检查
完整主体为一个封闭、法向一致的连通网格，STL 导出回读通过。青色全部投影在灰色侧饰之内，贴合面约 49.2 mm²，无悬空彩条。灰、青高度范围只在同一个水平面相接，没有互相穿插高度。侧饰保留在外侧，原导轨、按键孔、LED 光路没有重设计或缩放。为了减少换色，只保留单面装饰，另一面不做独立青色。

**侧放不等于免支撑**：导轨内侧、孔边及悬空处由你切片预览决定支撑。未验证层间强度、按钮行程/回弹、锁止、腕绳承载或手柄实际适配。原作者方案没有独立弹簧，且从控制器底部滑入，与原厂锁止不同；别强插，也别依赖试印件进行挥动游戏。
