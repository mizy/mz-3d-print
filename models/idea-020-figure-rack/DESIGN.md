# idea-020 桌面发带晾架「小人晾架」

> 主人的话（2026-10-25）：一个二次元人物，左右手各持一根晾杆，靠小人本体当支架来晾发带。
> 需求卡片在台账 `runtime/print-ideas.json` 的 **idea-020**；上一版 idea-018「龙门晾架」不动，本文件只说这一版。

**一句话结论**：`94 × 110 × 89.2 mm`、一件打印、全程免支撑、纯重力固定。底盘够宽且**所有挂点水平投影都落在支承多边形内**，
所以「单侧挂满 3 条湿发带（120g）」按 `docs/stability-load-analysis.md` 的判据**不存在有限倾覆载荷**（组合重心距最近支承边还有 34.2mm）；
顶面配重槽塞硬币是**可选**的，作用是把「被人碰一下」的水平推力阈值从 106g 抬到 148g（+40%），不是防翻倒的必需品。

## 1. 方案取舍（先解决「站不站得住」，再谈好不好看）

主人给的形态是**固定的**（小人左右手各持一杆）。能选的是：**杆的走向、底盘形状、配重怎么装、杆端怎么挡、手怎么握**。
逐条算数字再定：

| # | 选择 | 数字依据 | 结论 |
|---|---|---|---|
| A | **杆轴沿 Y（前后向），手心夹在杆中段** | 挂点在 `(±32, ±35)`：对底盘轮廓内距 **15.0mm**；组合重心余量 **34.2mm** | **选它** |
| B | 杆轴沿 X（左右横伸），两手各握一根 | 最外挂点会跑到 `|x|=67`，探出底盘 20mm；组合重心余量掉到 **20.3mm（−41%）**，且杆与手臂同向、握姿别扭 | 否 |
| C | 底盘用「长条（stadium）」轮廓 | 挂点 `(±32,±35)` 正对四角，大圆角把内距吃到 **只剩 3.1mm** | 否 |
| D | 底盘用 **圆角矩形 94×104 / R12**（本方案） | 同一挂点内距 **15.0mm**；代价 +16g（满打 164→180g） | **选它** |
| E | 「藏在底盘内部」的封闭配重腔（底面开口） | 平顶腔的免支撑桥接上限 **15mm < 硬币 Ø25**（`docs/stability-load-analysis.md` 口径 + 本项目 `BRIDGE_WIDE_MAX_W`）；11mm 厚的底盘里做不出 | 否：**打不出来** |
| F | 封闭式凹腔改用 30mm 高「台座」或另出一件盖子 | 台座 = 整件重心抬高 20mm；另出盖子 = 一处装配（主人要求一件打印） | 否 |
| G | **顶面开口的环形配重槽**（本方案） | 环形槽面积 **6705mm²**，平放 Ø25 硬币 9 枚/层、深 5mm 可叠 2 层 = **18 枚 ≈ 110g**；槽壁竖直、槽底朝上 → **零悬垂** | **选它** |
| H | 杆端做**球头** | 实测 OCC 球面在极点三角化会留重复有向边（**非水密**，`check_model` 报错），且球底那圈是陡悬垂 | 否：改六棱**挡边**（主人原话允许「球头/挡边」） |
| I | 手做「掌心平托」（杆搁在手心上） | 平托时杆下方**没有**实体 → 杆会滚、也谈不上夹持；环握在杆上下各有 **4.33mm** 实体包住 | **必须环握** |

**取舍一句话**：这一版的稳定性**不靠配重，靠「杆别伸到底盘外面去」**——底盘宽 94mm（= 肩宽 30 的 3 倍）、长 104mm、
挂点全在多边形里，所以自重（180g）就够压住 120g 的湿发带；配重槽是给「被人撞一下」「桌面有坡度」这类**横向扰动**留的余量。

## 2. 结构：谁受力、力怎么走

```
          挡边 ──┐                                              ┌── 挡边
    ═══════════╪══════════ 晾杆（六棱柱，沿 Y，±50，含挡边总跨 110）═══════════╪═══════
               │   ┌────┐                                        │
        ┌──────┴───┤ 拳 ├───┴──────┐        ← 环握：拳半高 7.36 > 杆半高 3.03，上下各包 4.33mm
        │   头球 r20 │    │         │
        └──┐  (切平顶)└────┘      ┌──┘      ← 双臂：与竖直 38.7°（≤45° 免支撑），根部埋进躯干 2.2mm
           └────────┬─────────────┘
                    │ 躯干（锥台 r12→15，肩宽 30）
                 ╭──┴──╮
                 │裙摆 │   ← 锥台 r15→12（侧面 84° 自支撑），底部咬进底盘 1mm
      ┌──────────┴─────┴──────────┐
      │  ▓▓▓▓ 配重槽（环形，宽26 深5）▓▓▓▓ │   ← 槽底朝上的环形槽，塞硬币用
      │  ▓▓▓  中央台（34×44）：站小人  ▓▓▓ │
      └───────────────────────────────┘     ← 底盘 94×104 厚 11，R12 圆角，底面整块贴桌
```

- **载荷路径**：发带 → 晾杆（双悬臂，手心是支点）→ 拳（环握，剪力 + 力偶）→ 手臂（斜撑，根部弯矩 28.2 N·mm）→ 躯干 → 裙摆 → 底盘 → 桌面。
  整条路径全是**并成一体的实体**，没有任何配合面/螺丝/胶。
- **杆沿 Y 的力臂账**：手心在 `|x|=32`，杆从手心向两端各悬出 50mm；发带最外挂点在 `y=±35`（= 杆端 50 − 发带宽 30/2）。
  这个点的水平投影到底盘轮廓还有 **15.0mm** 内距 → 竖直载荷的力线落在支承多边形**内部**，对稳定性的贡献是**正**的。
- **环握的几何证据**：拳是一个绕杆的六棱柱（外接半径 8.5，杆 3.5）。拳半高 `8.5·√3/2 = 7.36` 比杆半高 `3.5·√3/2 = 3.03` 大 **4.33mm**，
  也就是**杆的上方和下方各有 4.33mm 实体**——这正是「手指围合」与「掌心平托」的分界（平托式下方不会有料）。`check.py` 卡的就是这一条。
  （一件打印做不出真正「一圈环 + 一圈空隙」的活动环：空隙小于 0.3mm 会打在一起、大于 0.3mm 手就掉了；所以环握落成**融合的环状拳**。）
- **杆端挡边**：六棱柱 r=6.2 × 长 5，比杆粗 **2.7mm** 的台阶——发带顺杆滑到端头会被这圈台阶卡住。六棱（平顶平底）而不是球：
  球底的极点三角化不水密（§6），而且球底那圈是陡悬垂；六棱挡边朝下的只有一条 6.2mm 宽的窄棱。
- **底盘**：94（X）× 104（Y）× 11，四角 R12，底面整块贴桌 → 贴床 **9651mm²**（底盘外接矩形的 99%）。
  宽度链：`2×(外壁环 4 + 配重槽 26 + 中央台 17) = 94`。中央台（34×44）正好站裙摆（Ø30），四周一圈就是配重槽。

### 4.2 「单侧挂满会不会翻」——逐工况（PLA，含配重对比）

| 工况 | 总重 | 组合重心 (x, y) | 距最近支承边 | 倾覆临界外伸 |
|---|---|---|---|---|
| 空载 | 180.7g | (0.0, 0.0) | **47.0mm** | —（无载荷） |
| 单条湿发带（40g，挂杆端） | 220.7g | (−5.8, 6.3) | **41.2mm** | 212.3mm |
| **单侧挂满 3 条（120g，自杆端向内密排）** | 300.7g | (−12.8, 2.0) | **34.2mm** | **70.8mm** |
| 单侧挂满 3 条（三条都按杆端质点 = 保守上界） | 300.7g | (−12.8, 14.0) | **34.2mm** | 70.8mm |
| 两杆各挂满 3 条（6 条 240g，超载） | 420.7g | (0.0, 2.9) | **47.0mm** | 35.4mm |
| 单侧挂满 3 条 + 配重 72g | 372.7g | (−10.3, 1.6) | **36.7mm** | 70.8mm |

- **判据**（`docs/stability-load-analysis.md` §7）：稳定条件 `m0·d0 + mL·dL ≥ 0`，`d` 是重心/载荷投影到支承边直线的**有符号内距**（正=内侧）。
- **明确回答**：
  1. **单侧挂满 3 条不会翻**：每个挂点的水平投影都**落在支承多边形内**（最紧的那个在 X 向内距 **15.0mm**，Y 向 17mm）→ `dL > 0` →
     这个位置**不存在有限的竖直倾覆载荷**（形式上安全系数 ∞）。换个数说：要让 120g 把架子压翻，得把它们挂到
     距最近支承边**外伸 70.8mm** 的地方（而实际是在内侧 15.0mm）。
  2. **配重腔不是必需品**（防翻倒用不上），但**值得留**：它把「被撞/被推」的水平推力阈值从 **106.1g → 148.4g（+40%）**（单侧挂满时 128.6g → 170.9g）。
     默认口径 72g（12 枚 1 元硬币）；整个槽塞满约 **110g（18 枚）**。
  3. 超载一倍（两杆各 3 条 = 240g）仍余 47.0mm 余量——底盘比负载重得多，是「怎么挂都不会翻」的根本原因。
- **横向扰动阈值**：绕最近支承边、推力作用在杆高 80mm 处 → 空载 **106.1g**、单侧挂满 **128.6g**、配重后 **148.4 / 170.9g**；
  平移滑动阈值 **120.3g**（μ=0.40 木桌面）/ **72.3g**（μ=0.25 保守）。**滑动比翻倒先发生**：桌面有油/有水时会先滑，不会先翻。

### 4.3 晾杆与手臂的弯曲应力 / 挠度（Euler-Bernoulli 悬臂，公式写死在 `model.py`）

| 构件 | 载荷 | 截面 | 弯矩 | 应力 / 安全系数 | 挠度 |
|---|---|---|---|---|---|
| 晾杆（手心夹持 → 双悬臂，悬出 50mm） | 单条 40g（挂 y=±35） | 六棱 A=31.8mm² I=81.2mm⁴ W=26.8mm³ | 13.7 N·mm | **0.51 MPa**（PLA 97.6× / PETG 91.7×） | 端部 0.058mm、跨中 0.0072mm |
| 晾杆 | 一根杆挂满 3 条 120g | 同上 | 41.2 N·mm | **1.54 MPa**（PLA 32.5×） | 端部 **0.173mm**、跨中 0.022mm |
| 晾杆 | 湿毛巾 300g（误用） | 同上 | 103.0 N·mm | 3.84 MPa（PLA 13.0×） | 端部 0.431mm |
| 手臂（斜撑，根部 r=4.5） | 一根杆挂满 120g 压在一只手上 | 圆 A=63.5mm² I=321mm⁴ | 28.2 N·mm（= P×水平力臂 24mm；横向分量法交叉验算同为 28.2） | **0.40 MPa**（PLA 126× / PETG 119×） | 端部 0.0124mm |

- 弯曲强度**完全不是瓶颈**（安全系数 30–130×）。真正的风险是**倾倒/滑动**与**长期蠕变下垂**，不是断裂。
- 手臂还承担杆上发带偏挂带来的扭矩 **5.9 N·mm**（三层重叠，量级可忽略）；未做有限元（本机没有 FEM 求解器），
  上表是「等截面悬臂 + 保守支点」的解析上界，比实际偏保守（连壳体壁参与承力都没算）。

## 5. 可打印性（免支撑的数字，全部从 STL 网格实测）

- **朝下平面**：全件只有 **10 块**，最宽 **8.50mm**（两个拳的底棱；其余是杆底棱 3.5、挡边底棱 6.2），合计 **909mm²**。
  判据上限 15mm（`BRIDGE_WIDE_MAX_W`）→ 都是窄棱桥，**不需要支撑**。
- **陡悬垂**（面法线离「正下方」<45° 才算需要支撑）：**908.7mm² = 朝下平面面积**，即**除这些窄棱外一个陡悬垂面都没有**，
  只占整件表面积 **2.22%**。这条是这么做到的：手臂抬起 **38.7°**（≤45°）、裙摆侧面 84°、躯干侧面 83°、
  头球从肩台长出来那一圈 sin=**0.748**（≥0.707，等效 ≥45°）。
- **最小实体**：晾杆底棱 3.5mm（0.4 喷嘴 8 圈），底盘外壁环 4mm、配重槽底 5mm、手臂根部 Ø9、拳底棱 8.5 —— 全部 ≥1.6mm。
- **打印姿态 = 模型姿态**：Z 向上、底盘底面整块贴床（最低点 z=0.0000）；无装配、无支撑、无裙边需求（贴床 9651mm²）。
- **材料预算**：145.7 / 923 cm³ 外廓 = **15.8%**（skill 口径 ≤35%）。
- **成本**（`cost.mjs`，元/kg 取自 `runtime/filament-prices.json` 2026-10-24 快照）：
  - **PLA**（32 元/kg）：预计 **87.3g**、3.5h、**3.17 元**（满打上限 180.3g / 5.77 元）
  - **PETG**（30 元/kg）：预计 **89.4g**、3.5h、**3.05 元**（满打上限 184.7g / 5.54 元）
  - 湿发带场景 PETG 更合适（耐水、不脆）；要最便宜就是 PLA。

## 6. 建模上踩过的四个坑（都在 `check.py` 里留了对应断言）

1. **OCC 球面在极点三角化不水密**：`export_stl` 出来的球在极点留**重复有向边**，`check_model` 直接判 FAIL。
   → 头球做成「上下各切一刀的球带」，顶端切掉一个 R1.5 的小平顶（`head_top_flat_r`）：极点被切走，网格水密；
   代价是头顶有一个 Ø3mm 的平顶（视觉上几乎看不出，也顺手成了这版小人的记号）。
2. **共面贴合 → 非流形边**：杆端面原本正好落在挡边内端面上（共面），OCC 并集留退化面 → `有向边重复 2 条`。
   → 所有接头一律**体积咬合**（挡边往杆里咬 1mm、裙摆咬进底盘 1mm、躯干顶咬进头球 1mm）。
3. **手臂根部露出**：肩关节原来在 `|x|=11`，根部切面（Ø9，法线朝下 38.7°）有一角探出躯干，形成一块**朝下斜面**（陡悬垂）。
   → 根部挪到 `|x|=8`，`check.py` 用 72 个采样点验「整块埋在躯干里」（现埋深 2.23mm）。
4. **轮廓形状吃掉挂点内距**：底盘原设计是圆角长条（R47），最外挂点 `(±32,±35)` 正对四角、内距只剩 **3.1mm**。
   → 改成圆角矩形 R12，同一挂点内距 **15.0mm**（+11.9mm），代价 +16g。

## 8. 待主人实测 / 拍板清单

按影响从大到小。**第 1–3 条只是改 `model.scad` 里的数**，第 4、5 条要改形态（不是加参数）。

1. **发带的实际宽度与湿重**（现在按 30mm / 40g 估）——直接决定「一根杆能挂几条」：`band_span` 一改，`bands_max × band_span ≤ bar_len` 就跟着变。
2. **小人的造型**：现在是「无五官的 Q 版圆头 + 锥台身子」（刻意不带脸/发型，避免照抄参照手办，也避免单色 PLA 上打不出来的细节）。
   要脸/发型/耳朵，得另说：要么走浮雕（`make_relief.py`）、要么分件上色，本机单件免支撑打不出这类细节。
3. **总高**：现在 89.2mm（`head_r=20`、`torso_z_top=56`、`bar_z=80`）。主人之前默认提过 100mm —— 要 100 就把 `bar_z`/`torso_*` 一起放大，
   底盘不用动（挂点仍在轮廓内）。
4. **杆数**：现在是**左右各一（2 根）**。主人卡片里还留了「背后第三根」：那不是加参数，是重新排布（再加一对拳 + 一根横杆），要重画。
5. **可拆杆**：现在整件一体、无装配。可拆要在手心留孔 + 留 0.2–0.3mm 配合间隙，强度与清洗方式都会变，要单独定。
6. **配重槽形态**：现在是**顶面开口的环形槽**（能塞 Ø25 硬币、零悬垂）。要「藏在内部看不见」的封闭腔，在 11mm 厚底盘里打不出来（§1 E 行的数字），
   得改成 30mm 高的台座或另出盖子——两条都要主人认可形态变化。
7. **杆端挡边的样式**：现在是六棱挡边（能打印、免支撑）。要圆球头就得接受球底那圈悬垂 + 极点三角化不水密（§6 第 1 条），
   真要做球头建议把球也切平顶。
8. **底盘要不要加硅胶防滑垫 / 浮雕「苗壮制造」**；桌面可用宽度是否放得下 `94 × 110`（杆端比底盘每侧多探 3mm）。

## 9. 已知限制

- **受力是解析悬臂上界**，不是有限元：本机没有 FEM 求解器（`docs/stability-load-analysis.md` 阶段 C 的工具链未安装）。
  好在载荷只有 0.4–1.2N，安全系数 30× 以上，粗模型足够下结论。
- **载荷按质点建模**：一条湿发带 = 挂点处 40g 竖直力线（质心高 40mm）。真实发带是柔软的环，垂下的一段会**落在底盘上**，
  那部分重量直接由桌面承担 → 本模型对倾倒**偏保守**（真实更稳）。
- **只做静态、只受重力**：没算刚体动力学（碰撞/滑动过程）、没算桌面倾斜、没算侧向冲击的时间过程；柔性发带的摆动也没算。
- **材料数据是名义值**（PLA E=3500MPa σ=50MPa / PETG E=2000 σ=47），打印方向、层间强度、填充率都没进模型；
  长期载荷下的蠕变只在结论里定性提到（应力只有强度的 1–3%，量级上不成问题）。
- **配重槽顶面开口**：会积灰/积水，硬币看得见；槽底 5mm 平放硬币是俯视可见的。
