# CAD 原型评审

0. **默认只维护 `latest/`。** 用户没有明确说「归档」时，同一个项目的评审 HTML、总装 STEP、分件、配置、校验和都在固定 `latest/` 路径及文件名内更新。不用 V19B、V19C 等编号目录堆放尝试，不因交付一轮评审就归档。正式归档一律由用户明确触发；已经归档的正式版不动。未通过检验的方案在项目外试做，不把它当成可打印的 latest。
0.1 **项目评审统一从 HTML 交付。** 每次有要确认的模型或装配，先原位更新并核验项目的 `latest/index.html`，再告知用户。把可旋转 3D、实际 STEP 的三视图和尺寸引线、配合验证、明确的待确认点及同批 STEP/3MF 下载放在同一评审入口。相关文件链接用本地相对路径；图和附件可附在消息中，但不替代 HTML 交付。若旧构型仅用于对照，显式标记，不让它与本次可打印下载混淆。未获解除切片限制时只验几何和包结构；不运行切片或发送打印。
1. **先给用户确认。** 从项目最新可核实的原生模型、已批准尺寸和真实配合件开始。先用设计图确认结构与关键尺寸，再交可打印的 STEP；已明确授权制作则继续，不重复确认。把「草案」「评审用 STEP」「已批准版」分开标记；评审草案在 latest 更新，不覆盖已归档正式版。未经确认不改已批准的孔径、壁厚、配合、公差、安装方向等关键尺寸。

   - **复用已验证的配合件，就复制整套配合几何。** 例如「侧板后上④复用已验证的后下偏心件」时，从已验证的 CAD 基线复制、平移或镜像整套配合：偏心件和拉杆的锁头、T 槽／卡座、入口与导入、承力肩和接触面。不是沿用名称、参数或几个尺寸后另画卡座。保持配合基准、局部间隙、装入及锁定方向；逆变换后比对配合几何，再实查两侧各自的插入、锁定和取出路径及相邻件干涉。当要求「只挖一样的孔」或「外轮廓齐平」时，只复制孔、槽的负体和工作配合面；不要搬运工字截面、翼缘、凸台等外形。以原板平齐外廓为独立基准检查，不能靠增加包络掩盖干涉。周围避让、加料或减料单独标注；如扣合硬件、公差或其他部件不能原样复用，先说明不一致处及原因，请用户确认后再改。
   - **交付前自己复核图纸和配合，不把细节检查留给用户。** 标为同款或对称的接口，从同一个实体基准和同一量轴复核；例如侧板④/⑤从同一后端面量，分别标注入口、槽底、有效深度、宽高、锁止肩和轴距。复制只允许预期变换，本例仅沿 Z 平移；比较导出回读后的负体/配合面双向差集和投影尺寸，禁止只看截面或把截断的结果写成同款。复核整机闭合及动作包络，对照 HTML 的引线终点、可见/隐藏线、尺寸和 STEP，确认报告写明任何不可用装配。若同深与避让冲突，保留经确认的设计基准，不擅自移动接口、改料件或仅凭零干涉宣称锁住。
2. **严格三视图是交付门槛。** 每个不同零件必须有正视、俯视、侧视三张正投影视图；相同零件可共用已标明的图纸，剖视或局部详图只作补充，不能代替三视图。三个视向须互相垂直，统一基准、单位和比例，并标明观察方向；同一尺寸在各视图里投影必须一致。只用本次导出的实际 STEP 生成，不描截图、不凭感觉补画。交付前逐图核对图形轮廓、共享方向的尺寸、可见线／隐藏线、孔心、尺寸线及引线编号，确认图文和 STEP 一致。任一项失败先修图再交付，不让用户代查。
   - **同一几何生成评审图版。** 用同一版实际 STEP 的正投影生成正视、俯视、侧视及最能解释结构的剖视或第四正投影视图，不用透视渲染或手绘轮廓充当实测工程图。以一份本地离线 `index.html` 汇总；图板注明版本、视向、基准、坐标、单位 mm 和零件编号，尺寸用明确的尺寸线、引线和图例标注。标出关键间隙是单边还是总量、配合深度及有效行程。尚无 STEP 的图注明「概念图／尺寸待确认」。
   - **按实际装配逐点检查标注，不能只标本轮改动。** 对照 STEP、分件和装配清单，给每块板每个需装、插、扣、拧或承托的位置编号并用引线指到真实几何，说明配对零件、入口或操作面、方向、是否可选及重要基准尺寸。通用抽屉侧板至少标前下／后下／后上拉杆卡扣、双侧托轨、拨片轴座、前后叠层榫与底槽、止退键；后板区分四个轮座，前梁区分两端。被遮挡的接口用带图例的虚线、端视或剖视，不用引线指向错误面。已有项目 HTML 就原位更新，同时更新可重建的标注配置与校验清单；只补标注时不改 STEP。
   - **三视图共用比例，并独立核对投影。** 每个零件三视图用同一个 mm 比例和等宽视窗，不只核对 SVG viewBox，还要查 CSS 断点和打印样式。将投影线的范围对照按该视向旋转后的 BRep 实际边界；可见圆孔直接读取解析圆的中心、轴向与直径，自动绑引线，避免用近似点。各视图的编号连续；非孔的支撑轮廓另标，不能混编号。配合孔相同与相对外边的尺寸相同是两回事，必须分别核对、标清。
3. **交付真 STEP 与可用的 3D。** 优先交支持解析平面、圆弧、圆柱等曲面的 BRep STEP，不把三角网格封装成 STEP；需快速改尺寸时一并交可编辑的参数源，不能把 STEP 本身当作特征树。离线 HTML 的 3D 视图从对应 STEP 生成、可旋转缩放并复位，按需显示独立零件和装配位。网格只用于网页预览，不作为尺寸依据或制造主文件。资源内嵌或使用本地相对路径，不依赖联网；断网打开，实际检查按钮、四图与下载链接。
4. **验证装配，先做小样。** 回读导出的 STEP，确认单位、包络、实体数、零件方向和接口；用实际配合件核对孔、槽、卡扣、承托、装入方向及深度，沿插入／抽出／拆卸路径检查干涉，注明采样姿态或是否做了连续扫掠。把有争议的接口截成低耗材试装小样，保留关键壁厚、导入角、公差和打印方向；先确认装得进、卡得住、取得出，再整件打。除非 zhuang 明确要求，不做切片、不打开切片器代验。
5. **只报有证据的结论。** 交付时列出相对于基线改了什么、保留了什么，以及分别已做哪些检查。区分图面核对、CAD 干涉、仿真和实体打印结果；未测试的项目明确标注。CAD 零干涉不等于打印公差、实际承载、按压手感或免支撑已验证。
